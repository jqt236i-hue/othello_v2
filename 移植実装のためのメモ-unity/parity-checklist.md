# Unity 移植 Parity Checklist

このチェックリストは、Unity/C# 版が JS 版と同じゲーム結果になるかを確認するために使う。

## スコープ

対象:

- CPU 対戦
- リバーシモード
- 全カード挙動
- 演出イベント順
- 盤面状態
- 手札/山札/捨て札
- ローカル設定

対象外:

- ランキング
- オンライン対戦
- ガチャ
- ストーリー
- デッキ作成機能

## 基本ルール

- [ ] 初期盤面が一致する。
- [ ] 盤面サイズ `4..10` と既定 `8x8` が一致する。
- [ ] 偶数サイズ、`7x7`、その他奇数サイズの初期配置が一致する。
- [ ] 通常合法手判定が一致する。
- [ ] 通常反転結果が一致する。
- [ ] パス判定が一致する。
- [ ] 勝敗判定が一致する。
- [ ] 布石獲得が一致する。
- [ ] 数字マスの処理が一致する。
- [ ] 数字マスが配置時に消費され、破壊後も復活しない。

## 手札/山札

- [ ] 初期手札枚数が一致する。
- [ ] 初期手札が黒白とも 0 枚になる。
- [ ] 手札上限が 5 枚で、5 枚時の通常ドローが失敗する。
- [ ] デフォルトデッキが有効カードから重複なし 30 種で作られる。
- [ ] 黒白のデフォルトデッキ内容が共通で、山札順だけ別シャッフルになる。
- [ ] draw 結果が seed に対して再現できる。
- [ ] 捨て札への移動が一致する。
- [ ] 手札破壊が一致する。
- [ ] `enabled:false` のカードが通常山札に入らない。
- [ ] `enabled:false` の 6 件が連続効果の定義としては扱われる。

## カード使用

- [ ] cost 不足時に使えない。
- [ ] 使用条件付きカードの可否が一致する。
- [ ] 即時解決カードの結果が一致する。
- [ ] 次配置効果カードの pending が一致する。
- [ ] 対象選択カードの選択候補が一致する。
- [ ] キャンセル可能/不可が一致する。
- [ ] 複数段階選択が一致する。
- [ ] pending selection 33 種類の kind / turnOutcome / cancel 可否が一致する。
- [ ] hand overlay 系の天の恵み、断罪の意志が pending として状態化される。

## 特殊石/marker

- [ ] 保護系 marker が一致する。
- [ ] 幽霊、残像、復活系の挙動が一致する。
- [ ] 多動系の移動が一致する。
- [ ] 破壊龍、落雷、究極破壊神の破壊対象が一致する。
- [ ] 救済神の復活対象と所有者が一致する。
- [ ] 悪食、ロボット掃除機、意志狩りの移動/破壊が一致する。
- [ ] 持続ターンの減算タイミングが一致する。
- [ ] 狭義の特殊石化カードが、配置直後から最終見た目で表示される。

## 盤面変形

- [ ] 盤面拡張の追加セルが一致する。
- [ ] 盤面縮小の穴化対象が一致する。
- [ ] 隕石の穴化が一致する。
- [ ] マステレポートの移動元穴化が一致する。
- [ ] 封鎖中の配置/移動不可が一致する。
- [ ] 凍結中の反転/破壊/持続減算停止が一致する。
- [ ] 破壊+穴化時の救済神 flush 順序が一致する。

## 追加配置/連鎖

- [ ] 二連投石が一致する。
- [ ] 三連投石、四連投石、無限投石の定義が一致する。
- [ ] 追加配置中にターン開始効果を再実行しない。
- [ ] 二連鎖、三連鎖、四連鎖、無限連鎖が一致する。
- [ ] 連鎖後の破壊/生成/反転イベント順が一致する。
- [ ] `TRIPLE_*` / `QUAD_*` / `INFINITE_*` 系が通常山札に出ず、連続効果としてのみ到達する。

## PresentationEvent

- [ ] カード使用 event が出る。
- [ ] 宝箱でも `card_use_button` → `treasure_gain` の順で再生する。
- [ ] 手札破壊が fade out 系 event になる。
- [ ] 反転前に最終見た目へ切り替わる。
- [ ] `TRAP_WILL` は公開されるまで通常石見た目を保つ。
- [ ] 破壊/生成/移動 event の順序が一致する。
- [ ] 封鎖と凍結は専用表示を使う。
- [ ] spawn 系ポジティブ強調が出る。
- [ ] 専用演出 profile が必要な効果を区別する。
- [ ] effect block 単位で destroy / spawn / rescue の表示文脈が保持される。
- [ ] GameCore が Unity の Animator / Audio / Particle を直接触らない。

## CPU

- [ ] CPU が `GameCommand` を発行する。
- [ ] CPU が GameCore 状態を直接破壊しない。
- [ ] CPU の乱数が seed 管理される。
- [ ] CPU が対象選択 pending を経由する。
- [ ] 標準 `8x8` 以外で安全な通常判断へ切り替わる。
- [ ] Lv6 の共有 profile / fallback 方針が実装上分岐として明示される。
- [ ] CPU 発話を実装する場合、固定文方式で外部推論を前提にしない。
- [ ] CPU 対戦が最後まで進行する。

## リバーシモード

- [ ] カード、デッキ、手札、布石、数字マス、特殊石、カード由来ターン開始効果が無効になる。
- [ ] カードリバーシ専用 UI が非表示になる。
- [ ] パス判定が通常リバーシと同じく合法手 0 のみになる。
- [ ] 白 CPU が白設定の CPU レベルで動く。

## ローカル保存/設定

- [ ] 音量設定が保存される。
- [ ] 演出速度設定が保存される。
- [ ] CPU 難度が保存される。
- [ ] 盤面サイズ設定が次の新規対局/リセットから反映される。
- [ ] 直近の対戦設定が保存される。
- [ ] CPU 対戦リザルトで観測石所持数が更新される。
- [ ] 初期対象外機能の保存項目が混入していない。

## リザルト

- [ ] リザルト表示順が `勝敗タイトル` → `石枚数` → `最終スコア` → `スコア補足` → `観測石獲得` → `スコア内訳` → `モンスター台詞` になる。
- [ ] CPU 対戦の引き分け/敗北で `観測石 +100（基本100 / 追加0）` になる。
- [ ] CPU 対戦の勝利で `100 + 追加ドロップ` になる。
- [ ] 追加ドロップが `100..3000`、`10` 刻み、線形重み `weight(k) = 291 - k` になる。
- [ ] ランキング送信や共有ランキング文言が出ない。

## 除外機能

- [ ] ランキング UI / API / 保存項目がない。
- [ ] オンライン対戦 UI / 通信 / room / reconnect 処理がない。
- [ ] ガチャ UI / 観測石消費導線がない。
- [ ] ストーリー進行 UI がない。
- [ ] デッキ作成 UI / deck code / カスタムデッキ保存がない。

## 完了判定

- [ ] 固定 seed の CPU 対戦サンプルで JS 版と Unity 版の最終盤面が一致する。
- [ ] 固定 seed の CPU 対戦サンプルでクラッシュせず決着する。
- [ ] リバーシモードでカードリバーシ専用 UI とカード系ルールが無効になり、対局が決着する。
- [ ] 全有効カードを最低 1 回ずつ使用できる。
- [ ] 全対象選択カードの候補表示と解決が確認済み。
- [ ] 全専用演出 profile が汎用演出に潰されず対応表に載っている。
- [ ] 初期対象外機能が UI に表示されていない。
