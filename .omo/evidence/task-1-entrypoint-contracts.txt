# Entrypoint contract matrix

## CLI scripts
- package.json `serve` -> `node scripts/serve-with-fallback.js`.
  - Broken baseline: root wrapper used to only `require('../dist/scripts/serve-with-fallback')`; dist guard `require.main === module` did not fire.
  - Current contract: root wrapper must execute dist CLI as a child when run directly, while preserving importable helper API.
  - Verification: `node scripts/serve-with-fallback.js --help`; live start probe on port 8011 returned HTTP 200.
- package.json `worker:prepare` -> `node scripts/prepare-worker-assets.js`.
  - Contract: prepares worker-public mirror from root source/build artifacts; must not overwrite `workers/match-worker.mjs` export bridge.

## Browser scripts
- Root `index.html` references 238 local script files.
- Root script files are TypeScript-migration CommonJS wrappers and are not safe as browser script-tag payloads.
- `worker-public` is the browser-ready assets directory and is now the default local serve root when no explicit root is supplied.

## Worker
- wrangler.toml `main = "workers/match-worker.mjs"`.
- Durable Object binding class_name = `MatchRoomDurableObject`.
- Contract: the module entrypoint must have a statically visible named ESM export `MatchRoomDurableObject` and default Worker export.
- Current bridge imports CommonJS dist default and explicitly exports `MatchRoomDurableObject` plus default Worker object.
- Verification: Node dynamic import keys are `["MatchRoomDurableObject","default"]`; `npx wrangler deploy --dry-run` shows `env.MATCH_ROOM (MatchRoomDurableObject)` binding and no missing export error.
