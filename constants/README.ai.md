# constants/ README.ai

## 役割

- 共有定数と領域別定数の正本をまとめる場所です。
- 同じ意味の値を複数の場所へ増やさないための補助メモです。

## 正本の置き方

- 共有意味の定数: `shared-constants.ts`（`shared-constants.js` は互換 shim）
- 領域専用の定数: `constants/`

## 変更ルール

- 同じ意味の値は 1 か所に置き、参照側をそろえます。
- 画面専用の値を `game/` に直書きしません。
- 広く参照される定数名を変える時は、呼び出し側を同じタスク内でそろえます。

## 確認

- 重複定義が増えていない
- 呼び出し側の更新漏れがない
- 置き場所が定数の意味と合っている
