# 第一進化特殊石

デフォルト立ち絵と三面図を元に想像で作成した、全40キャラ分の第一進化デザイン案です。各PNGは左から**正面・右側面・背面**の三面を並べています。

進化先の正本設定がないため、ここにある姿はすべて新規の提案です。元キャラの色や印象的なモチーフを受け継ぎながら、体格・輪郭・体の構造が変わるように設計しています。

## 3D化について

各画像は立体化を検討するためのコンセプト資料です。画像生成による三面図なので、寸法・左右対称性・細部の完全な一致を保証する設計図ではありません。実際のモデリングでは、特に側面・背面の細部や各部の厚みを調整してください。
