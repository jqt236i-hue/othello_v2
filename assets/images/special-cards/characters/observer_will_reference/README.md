## 保持する外観

- 高く尖った、裂けた黒いフードと多層の衣装。
- 顔の内部は暗い空洞で、白く発光する単眼を持つ。人間の鼻や口は追加しない。
- 前面のリバーシ盤、白黒の駒、古びた格子の意匠。
- 細長い腕と、親指を含む片手5本の指、爪のある手。
- 静止時は長い衣装が身体と脚を覆い、元資料に近い輪郭になる。

## 必要な可動

| 部位 | できるようにする動き |
| --- | --- |
| 頭・首 | 胴体を正面に保ったまま左右を見る、上を見る、うつむく、軽く傾ける。単眼は頭部に追従する。 |
| 肩・腕 | 腕を前・横に上げる、肘を曲げる、前腕をひねる、手首を曲げる。 |
| 手指 | 指を個別に曲げる、開く、握る、指差す、親指と人差し指で駒をつまむ。 |
| 胴・腰 | 前後に曲げる、横に傾ける、胸と骨盤の向きをずらしてひねる。 |
| 脚・足 | 左右の脚を独立して動かす、歩く、膝を曲げる、片膝をつく、足首を曲げて接地する。 |
| 衣装 | 腕や脚の動きに追従し、歩行時に裾が開き、膝をついたときに布が垂れる。 |

## モデルとリグの構造案

衣装の下にも、首・胴・骨盤・両腕・両脚・手足のある連続した人型の身体を用意します。三面図の露出した脚は構造説明用であり、通常の着衣状態で常に脚を見せる指定ではありません。

骨格はルート、骨盤、背骨、胸、首、頭、左右の肩・上腕・前腕・手・各指、左右の太腿・すね・足・つま先を基本とします。手足の位置を指定して姿勢を作れるIKと、関節の回転を調整するFKを必要に応じて用意します。顔の向きは頭と首の回転で表現し、人間型の表情変形は必須にしません。

頭部のフードと肩の布は、首を回せるように独立して扱います。袖と胴の布も腕を持ち上げられる構成にし、肩・肘・股関節・膝には変形に必要な形状とウェイトを持たせます。

前面の長い盤を腰付近で分け、胸側と下へ垂れる部分が別々に動く構造を追加案とします。下側の盤と前後左右の衣装の裾は、脚の動きを妨げないよう分割・追従させます。衣装用ボーンまたは布シミュレーションの選択は、使用先の実行環境に合わせます。

## 画像を読み取る際の注意

追加の2枚はAI生成による形状・可動の提案で、寸法図や検証済みのリグ仕様ではありません。足の形、衣装内部の身体、盤の分割方法は元資料で確定していない補完案です。

複数の図で指・格子・駒の配置・衣装の境界に差がある場合、その差を別仕様として再現しないでください。外観の細部は元の詳細資料を優先し、追加図は身体のつながりと動作を読むために使用します。構造図の背面に見える格子も、背面に盤を追加する指定ではありません。関節位置と全体の比率は、制作時に全方向で統一します。

## 制作時の確認項目

- Aポーズで左右の身体構造と指の本数が揃っている。
- 胴を固定して頭を左右・上下に向けられる。
- 手を開く、握る、駒をつまむ動作で指が破綻しない。
- 腕を上げても肩や袖が胴体へ不自然に引き伸ばされない。
- 歩行・片膝立ち・胴のひねりで、盤や衣装が身体を大きく貫通しない。
- 足が接地し、膝と足首が自然な方向に曲がる。
- 元の着衣シルエットへ戻せる。
- 使用先に書き出したモデルでも骨格・材質・発光・アニメーションを確認する。

画像は制作の参考です。実際に動かすには、3Dメッシュに加えて骨格、スキニング、操作用リグ、必要なアニメーションの制作が必要です。ファイル形式・ポリゴン数・テクスチャ解像度は、使用する3Dソフトと実行環境に合わせて決めてください。
