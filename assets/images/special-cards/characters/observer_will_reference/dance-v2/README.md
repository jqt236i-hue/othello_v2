## 外観の基準と画像の優先順位

外観の基準は[元の三面図](../observer_will_turnaround.png)と[元の詳細資料](../observer_will_detail_sheet.png)。高く尖った裂けたフード、暗い空洞に光る白い単眼、長く細い爪のある手、黒い多層衣装、前面のリバーシ盤を保持する。鼻・口・人間の顔は追加しない。手指は親指を含めて片手5本。

ダンス用の着衣比率は01を基準にする。02・03は奥行きと背面を補う資料で、各画像の高さをそのまま別寸法として扱わない。04は衣装内部の補完案で、身体の細かな輪郭は01の着衣シルエットを保てるよう制作時に統一する。

05は部品の分け方を示す概念図。盤の寸法、格子数、駒の位置、衣装の取り付け金具は画像間で差があるため、部品図だけから新しい外観を決めない。盤の細部は元資料、ダンス時の上部・下部の分割位置は01を優先し、同じモデルで統一する。

## 動かすための構造案

頭のフードは頭に追従し、肩の布と分ける。首・肩・肘・手首・各指、腰・股関節・膝・足首が動く人型骨格を使う。胸の盤は胴側、下に垂れる盤は腰側の別部品として扱い、腰の曲げを硬い盤で塞がない。左右・前後の裾は脚を動かせる分割と追従を持たせる。

08は足の形と接地の参考、09は演技と姿勢の案。09の各姿勢は連続したアニメーションのコマではなく、同じ時刻やカメラを持つモーションデータでもない。

高品質のダンスに仕上げる際は、同じモデル上で足の接地、重心、関節の変形、指の本数、頭と肩の干渉、盤と脚の接触、衣装の追従を確認する。画像にはメッシュ、骨格、ウェイト、物理設定、振付は含まれない。モデル用のUVテクスチャや法線マップは、実際のモデルのUVに合わせて制作する。
