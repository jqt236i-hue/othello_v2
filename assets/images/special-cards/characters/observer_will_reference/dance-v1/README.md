# 観測者のダンス制作用素材 v1

元の `observer_will_turnaround.png` を外観の基準に、踊る3Dモデルの制作に使う追加参考画像です。内蔵画像生成ツールで生成しました。

- `observer-dance-a-pose.png`: 背景透過の全身Aポーズ。手足を分離して読み取りやすくした着衣状態。
- `observer-dance-construction-sheet.png`: 衣装内部の正面・側面・背面と、着衣でのダンス動作例。
- `generation-prompts.txt`: 使用した生成指示の全文。

画像は形状と動きの参考であり、3Dモデル、骨格、ウェイト、アニメーションは含みません。衣装の分割と腰から下の盤の独立は、ダンスの可動性を確保するための補完案です。細部や各方向に食い違いがある場合は、元の三面図・詳細資料を優先して制作時に統一してください。背面に盤は追加しません。

ゲーム内の表示には組み込んでいません。
