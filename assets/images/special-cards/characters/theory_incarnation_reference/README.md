## 今回反映した形状

- 顔は奥行きのある黒い空洞。人間の鼻・口・目は設けず、後頭部は棘で覆われた閉じた形にする。
- 翼は腕とは別に、左右の肩甲骨に当たる背中の位置から後方へ張り出す。翼の付け根と布の境目を読めるようにする。
- 背面は中央が開かない一枚続きの黒いマント。背面の銀色の縦帯を取り除き、前開きの服のように見える形を修正した。
- マントの翼用の穴は付け根の周囲だけ。背中の中央や裾まで続く切れ込みにしない。
- 前面の銀灰色の縁、盤面の格子と白黒の石、黒翼、長い袖、棘状の頭部は既存デザインを基準とする。

## モデリング時の扱い

全身形状は01、背中と翼の接続は03、細部の素材は02と04を参照します。頭部・襟・胴体・袖・マント・前垂れ・翼・石を分けて作る際の視覚資料として使用できます。

画像生成によるデザイン資料であり、同一の3Dメッシュから出力した正確な投影図ではありません。図間の羽根数・格子・石の配置・細かな棘や手の向きは完全には一致していません。左右の手は実モデルで鏡像関係を整え、寸法、関節位置、布厚はモデル上で合わせてください。03の断面と可動矢印は内部構造の制作案で、可動範囲を実測したものではありません。

新しい背面構造は今回のユーザー指摘を反映した制作資料として保存しています。ストーリーの設定文書やゲーム内の採用画像は更新していません。
