## 元画像への忠実さ

キャラクターが描かれている元画像は、そのキャラクターの顔・体格・配色・衣装を参照し、隠れた側面や背面を補完した。幽体などに人間の脚を追加していない。顕現石3体は `../images/special-cards/characters/` の大きい元画像も参照した。

追加の15種類は、ユーザーの「擬人化しない・元に忠実」という指示に従い、**人物設定から新しい姿を作らず、元の文字・記号・模様・石の材質を保持**した。元にない顔、手足、衣装は追加していない。

- 文字・属性模様・ハート・爆弾系の記号は周囲のオセロ石を除き、元図案を薄い形状として表現。真横は薄い断面、背面は裏側の向きとして補完している。
- 弱い石と金・銀・虹の石は、元画像に独立したキャラクターがないため、元の石の形と材質そのものを残した。
- 十字爆弾（CROSS_BOMB）は元画像どおり斜めの×、クロス爆弾（X_BOMB）は元画像どおり縦横の＋を使用。
- 森羅万象神の初回生成に加わった顔と宝石飾りは修正して除去済み。

小さい単一方向の元画像を参照した生成画像であり、画素単位の一致ではない。側面の厚みや背面は元画像で確定できない部分の補完。厳密な寸法図や立体モデルの保証ではない。CPU専用肖像・手のスキンは対象外。

内蔵画像生成を使用。

- 初回28枚: [生成指示.json](生成指示.json)
- 追加15枚と修正: [追加15種類の生成指示.json](追加15種類の生成指示.json)

追加15枚は各生成結果を目視し、三方向、元の主題、擬人化要素の不在を確認。保存した全43枚を読み込み、78個の元画像との対応とファイルの実在を確認した。

ゲームからは参照していない資料。ゲーム実装・既存画像・通常配信は変更していない。

## 不採用の試作

`不採用試作/` の4枚は人物設定から擬人化してしまったため不採用。完成フォルダ `三面図/` からは除外済み。

このフォルダ直下の `SACRIFICE_WILL-black-three-views.png`、`SACRIFICE_WILL-black-three-views-alpha.png`、`sna-three-views.png` は、透過指示が市松模様として描かれた初期試作。使用する画像は `三面図/` の43枚。
