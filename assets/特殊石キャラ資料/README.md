- 幽体石は短くまとまった体型。極悪多動魔・多動石・逃亡石・究極多動神は靴型を維持。
- 元絵が文字・記号・物体の種類は擬人化せず、そのモチーフの3方向資料とした。金・銀・虹・弱い石は元に別のキャラクターがないため、石本体の外観資料。
- 側面・背面の細部は画像生成による補完であり、既存の確定設定ではない。
- 盤界の執行者、理論の化身、盤理の観測者、作成済みの意志狩りの王は対象外。
- 旧2方向版は `旧版_前面・背面/` に保存。今回の完成版はこのフォルダー直下の `*_正面・側面・背面.png`。
- 参照元と実際の生成プロンプトは [生成記録.json](生成記録.json)。ゲームの画像差し替えは行っていない。
