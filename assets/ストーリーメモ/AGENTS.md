# ストーリーメモの作業方針

## 調査範囲

必要に応じて、リポジトリ全体（`C:\Users\quarr\Desktop\othello_v2`）のコード、仕様書、関連資料、および実際のゲームを調査・分析してよい。ストーリーや設定の現状、実装との対応、用語や挙動の根拠を確認するために利用する。

## STORY・設定の変更

STORY、世界観、登場人物、設定、関係性、時系列、用語、出来事など、このディレクトリの内容に関わる変更を行うときは、次の方針に従う。

- このディレクトリ以下にあるすべてのMarkdownファイル（`*.md`）を確認し、変更の影響範囲を洗い出す。
- 変更内容に関係する記述は、対象ファイルだけでなく、影響を受けるMarkdownファイルにも漏れなく反映する。
- ファイル間で、名称・用語、設定、人物や勢力の関係、時系列、因果関係、出来事の経緯、相互参照などに矛盾や記載漏れがないか確認する。
- 変更の影響を受けない記述は、不要に書き換えない。ただし、整合性を保つために必要な修正は省略しない。
- 既存のコードやゲームの挙動と資料の内容が食い違う場合は、依頼された変更の意図と確認できる根拠を踏まえて整理する。安全に判断できない矛盾は、推測で確定せず、問題として明示する。

変更後は、Markdownファイル全体をあらためて確認し、変更漏れ、古い記述、ファイル間の不整合が残っていないことを完了条件とする。
