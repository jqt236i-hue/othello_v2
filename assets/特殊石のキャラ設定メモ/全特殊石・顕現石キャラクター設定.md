# 全特殊石・顕現石キャラクター設定

## 対象範囲

- `01-rulebook.md` と `shared/special-stone-registry.ts` に基づく特殊石本体、および `shared/manifest-stone-registry.ts` に登録された顕現石を対象とする。
- 罠石と爆弾系は、今回のキャラクター設定対象から例外的に除外する。
- 石状態、盤面マーカー、配置時効果は含めない。
- 年齢は人間だった者は当時の年齢、人外は誕生または稼働からの年数とする。
- 性別表記は「男」「女」「不詳」のいずれかに統一する。

## 特殊石

### 1. 弱い石（PROTECTED）

- 性別: 男
- 性格: 臆病だが、誰かが危険にさらされると自分から盾になる。自信のなさを慎重さへ変えられる少年。
- 年齢: 15歳
- 口調: 柔らかな少年口調。「僕」「～だよ」「怖いけど、やってみる」が基本で、虚勢は張らない。
- 短いバックストーリー: 戦火の村で年下の子どもたちを地下室へ逃がし、自分だけ入口に残った見習い門番。その一夜の勇気が石に宿った。
- 未練: 最後まで守れなかった幼い妹に、「今度こそ怖くても逃げない」と伝えたい。

### 2. 強い石（PERMA_PROTECTED）

- 性別: 女
- 性格: 寡黙で忍耐強く、決めたことを年月がかかっても曲げない。守られるより、自ら揺るがない礎であろうとする。
- 年齢: 28歳
- 口調: 短く断定的な女言葉。「私」「焦るな」「まだ崩れない」。感情が高ぶるほど声量ではなく言葉数が減る。
- 短いバックストーリー: 雪山の砦を一人で守り続けた石工。補給が絶えても壁を直し、最後の避難民が峠を越えるまで門を開けなかった。
- 未練: 完成させられなかった砦の最後の一枚を、自分の手で積み上げたい。

### 3. 狙撃石（SNIPER）

- 性別: 男
- 性格: 冷静で几帳面。感情を任務から切り離そうとするが、一度守ると決めた相手への執着は深い。
- 年齢: 37歳
- 口調: 低く簡潔な軍人口調。「私」「射線良好」「任務を継続する」。冗談にも報告書のように返す。
- 短いバックストーリー: 山岳国境の監視塔で、姿を見せないまま村を守った狙撃手。最後の任務では敵ではなく、離反した親友へ照準を合わせた。
- 未練: 引き金を引く前に、親友が裏切った本当の理由を聞きたかった。

### 4. 幽体石（GHOST）

- 性別: 女

- 短いバックストーリー: 海辺の灯台で帰らぬ船を待ち続け、嵐の夜に命を落とした灯守の娘。今も境界の向こうから盤を照らしている。
- 未練: 最後の夜に灯台へ戻ってきた船に、誰が乗っていたのか確かめたい。

## 顕現石

### 27. 理論の化身（THEORY_INCARNATION）

- 性別: 不詳
- 性格: 純粋な知的好奇心の持ち主。感情を変数として扱うが軽視はせず、予測不能な心を最も美しい未解決問題だと考える。
- 年齢: 誕生から1年
- 口調: 中性的で学術的な口調。「当個体」「仮説を提示する」「その選択は興味深い」。感嘆の代わりに観測結果を述べる。
- 短いバックストーリー: 盤上で積み重なった無数の勝敗データが、ある瞬間に自己を証明して生まれた存在。誕生と同時に世界の大半を理解したが、自分が望まれた理由だけは式にできなかった。
- 未練: 一度も計算を介さず、ただ「好きだから」と何かを選んでみたい。

### 28. 盤界の執行者（BOARD_EXECUTOR）

- 性別: 不詳
- 性格: 傲岸不遜で自信に満ち、自分こそ盤界の法だと信じる俺様気質。例外も異論も力でねじ伏せるが、執行によって苦しんだ者の顔はひそかにすべて記憶している。
- 年齢: 980歳
- 口調: 尊大な俺様口調。「俺様」「俺様が執行してやる」「異議など認めん」。常に上から言い切り、私情を突かれたときだけ急に言葉が短くなる。
- 短いバックストーリー: 盤界で暴走した特殊石を裁くため、最初のルールから切り出された執行人格。千年近く命令どおり穴を開け続け、自ら判断する権利を持たなかった。
- 未練: ただ一度だけ、命令ではなく自分の良心で執行を取りやめたかった判決がある。

### 29. 盤理の観測者（OBSERVER_WILL）

- 性別: 不詳
- 性格: 老獪で好奇心旺盛な観察者。相手の秘密を見抜くことを愉しみ、何でも知っているように振る舞うが、観測結果を悪意で歪めることはしない。
- 年齢: 36歳
- 口調: 「～ぞよ」を語尾に付ける古風で得意げな口調。「余」「余が観測してやるぞよ」「その手札、見えておるぞよ」。核心を言い当てた後は満足そうに含み笑いする。
- 短いバックストーリー: 戦争を止めるため敵国の思考を読み続けた研究者。すべての作戦を理解できたのに、和平を申し出た相手の一通の私信だけは開封できなかった。
- 未練: 奪うためではなく信じるために、封を切らなかった手紙の言葉を知りたい。
