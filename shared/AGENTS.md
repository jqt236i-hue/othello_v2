# shared/ AGENTS.md

Runtime-portable contracts and pure helpers. Use this file with the root `AGENTS.md` as the local boundary guide.

## What belongs here

| Area | Examples | Notes |
| --- | --- | --- |
| Contracts / codecs | `deck-codec.ts`, `network-action-schema.ts` | Canonical shared contracts/codecs; adjacent `.js` files remain runtime-compatibility wrappers. |
| Shape / normalization helpers | board, player, snapshot, state hash helpers | Prefer shared helpers over caller-side duplication. |
| Runtime capability helpers | `cpu-lv6-runtime-capability.ts` | Canonical pure resolver; the adjacent `.js` file is a compatibility wrapper with no UI or worker side effects. |
| Generated shared catalogs | `observation-gacha-catalog-*`, `gacha-hand-catalog-*` | Generated by scripts, not hand-edit-first targets. |

## Rules

- No DOM, `window`, audio, rendering, timers, or hidden environment-dependent side effects.
- Do not bend shared contracts for a single caller's UI/game convenience.
- Boundary normalization belongs here when multiple runtimes need it.
- Generated shared outputs must be regenerated through the owning script.

## Duplication traps

- `shared/*` and `worker-public/shared/*` are root/mirror, not independent implementations.
- `shared-constants.js` lives at repo root, not under this directory.
- Network schema helpers must stay aligned with `workers/` and `ui/network/*`.

## Verification

- Use focused tests under `test/shared.*`, `test/network.*`, `test/ui.network*`, or caller-specific suites.
- Cross-runtime helpers should have browser/worker/headless-safe imports.
- `.ts` changes require `npm run typecheck` and `npm run build:ts`.
