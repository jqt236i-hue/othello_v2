# ターン進行正本

この文書は、1手番の中で何がどの順番で処理され、どの順番で見えるべきかを定義します。

カードリバーシでは、最終盤面が同じでも、処理順と見た目の順番が違うと別のゲーム体験になります。特にネット対戦では、片方の画面だけ特殊石が同時に動く、効果音が重なる、次の入力が先に通る、といった状態を仕様違反として扱います。

## 基本原則

- 1手番の中の処理順は固定です。
- 盤面に見えるアクションは、原則として1つずつ順番に再生します。
- 複数の特殊石が同じタイミングで発動条件を満たしていても、同時には動かしません。
- 1つの特殊石の移動、反転、破壊、生成、ハイライト、効果音、通常石化が完了してから、次の特殊石の処理に進みます。
- 結果計算を先にまとめて行う場合でも、プレイヤーに見える再生順はこの正本の順番を守ります。
- ランダム決定とネット対戦の結果一致は共通ルール正本に従います。

## 用語

### 手番

手番とは、1人のプレイヤーがターン開始処理を受け、必要ならカードを使い、配置またはパスし、終了判定と手番交代へ進む単位です。

パス、罠の意志、交換の意志など、石を通常配置しないカードで終わる場合も1手番として扱います。

### ターン開始効果

ターン開始効果とは、手番の最初に発動する継続効果です。

所有者ターン開始時にだけ発動する効果と、両者ターン開始時に発動する効果があります。両者ターン開始時の効果は、黒手番でも白手番でも条件を満たせば発動します。

### アクション

アクションとは、プレイヤーまたは特殊石が1回の意味ある処理を行う単位です。

例:

- 多動石が1マス移動する
- 破壊龍が敵石1個を破壊しようとする
- 時限爆弾が起爆する
- カードで石1つを選んでテレポートする
- 通常配置で石を置き、反転する

### 完了

完了とは、そのアクションに含まれる盤面変化、ハイライト、移動、反転、破壊、生成、効果音、布石表示、通常石化が見た目上も区切りまで終わった状態です。

次のアクションは、前のアクションが完了してから再生します。

## 1手番の大きな順番

1. 前手番から残った再生や入力ロックの完了
2. ラウンド開始ボーナス
3. ターン開始前に必ず処理する支払い・不足処理
4. ターン開始効果
5. ドロー
6. カード使用または手札破壊
7. 配置、対象選択型カードの解決、またはパス
8. 配置による反転
9. 配置後効果
10. 布石加算と布石差分表示
11. 手番終了時の毒・灼熱の石状態と特殊マスの残りターン減算、残り0になった石状態の破壊試行、特殊マス解除
12. 終了判定
13. 手番交代

この順番を飛ばしたり、後ろの処理を先に見せたりしてはいけません。

毒殺の意志を使った手番、火の意志が灼熱マスを成立させた手番、水の意志が治癒マスを成立させた手番、石が新たに毒状態または灼熱カウントを得た手番では、そのマスまたは石状態を同じ手番の終了時に減算しません。次に完了する手番から減算します。複数の毒状態・灼熱カウントが同じ手番に残り0になる場合は、種類でまとめず `createdSeq` 昇順に1個ずつ、赤ハイライト、破壊試行、破壊回避・復活などの解決、対象状態解除までを完了してから次の石を処理します。石状態による破壊処理をすべて終えてから、毒マス・灼熱マス・治癒マスを `createdSeq` 昇順で減算・解除し、その後に終了判定へ進みます。

各プレイヤーのターン開始時は、開始時点ですでに盤面にある治癒マス上の、そのプレイヤーが所有する特殊石本体へ持続ターン `+3` を先に適用します。その後、特殊石・爆弾・継続効果を通常どおり `createdSeq` 昇順で発動・減算します。同じターン開始処理中に水石が新しく作った治癒マスは、そのターンの加算対象判定には戻りません。

## ターン開始処理の順番

### ラウンド開始ボーナス

ラウンド開始ボーナスが発生する場合、最初の特殊石効果より前に処理します。

黒白の両者に同時に布石が入る性質のボーナスですが、表示上はラウンドボーナスとして1つのまとまったアクションにします。特殊石の移動や破壊と混ぜて表示しません。

### 支払い・不足処理

リボ払いの意志の返済など、ターン開始前に必ず発生する支払い・不足処理は、ドローや他のターン開始収入より先に処理します。

不足によって石が消える場合、その消滅とハイライト、効果音、布石差分を完了させてから次へ進みます。

### 特殊石・爆弾・継続効果の発動順

ターン開始効果を持つ特殊石、爆弾、継続状態は、原則として「その状態が盤面に登場した順」に1つずつ処理します。

登場順とは、その特殊石や状態が盤面上に成立した順番です。石が移動しても登場順は変わりません。複製、生成、救済、復活などで新しく生まれた石や状態は、その時点で新しい登場順を得ます。

同じ効果で複数の石が同時に生まれたように見える場合でも、正本上は生成された順番を持ちます。生成演出が1個ずつ再生される場合、その再生順が登場順です。

どうしても登場順が区別できない場合は、その状態が保持されている安定順を使います。この順番は同じ局面なら全プレイヤーで同じになり、画面の向きや通信状況で変わってはいけません。

ターン開始処理では、今回のターン開始中に発動可能な特殊石、爆弾、継続状態の個体集合を、ターン開始由来の最初の盤面・マーカー変更より前に固定します。

固定するのは個体の同一性、登場順、同値時の決定的な比較キーだけです。現在座標、所有者、対象候補、移動先、破壊対象、生成先、乱数結果、効果結果は固定しません。

固定後に支払い、破壊、救済、復活、生成などで消えた個体は、その個体の処理枠で生存確認に失敗した場合は発動しません。同じ座標・同じ種類の新規個体へ処理枠を引き継ぎません。

固定後に新しく生成、復活、付与された特殊石、爆弾、継続状態は、その同じターン開始処理では発動せず、次に条件を満たすターン開始から処理します。

ターン開始アンカーの基本順は `createdSeq` 昇順です。`createdSeq` が同値または欠損している互換状態では、ターン開始入口で取得した canonical marker 配列上の `sourceIndex` 昇順を第2キーにします。さらに比較が必要な場合は安定した `markerId` の文字列表現を第3キーにします。

この比較規則はローカル対戦、ローカルサーバー、Cloudflare Worker で同じでなければなりません。JavaScript エンジンの stable sort だけには依存しません。

### 1つの石に複数状態がある場合

同じ石に複数のターン開始効果や継続状態が重なっている場合、その石の処理枠の中で順番に解決します。

基本順は次のとおりです。

1. 石本体の特殊効果
2. 後から付与された継続状態の効果
3. 持続ターンの減算
4. 持続切れによる通常石化、消滅、進化

ただし、カード個別仕様で明確に別順が定義されている場合は、カード個別仕様を優先します。

持続切れと効果発動が同じタイミングで起こる場合、見た目は「効果発動、必要な移動や破壊や反転、最後に通常石化または消滅」の順にします。

同じ物理石に複数のターン開始対象がある場合、その処理枠の登場順は、その枠に属する対象のうち最小の `createdSeq` とします。枠内では石本体の効果を先に処理し、付与状態は `createdSeq` 昇順、同値時は状態の canonical sourceIndex 昇順で処理します。

同じセルに存在するという理由だけで、凍結、種、封鎖、穴、数字マス、顕現石などの盤面マーカーを物理石の状態枠へ統合しません。物理石へ付与された石状態だけを同じ処理枠の対象にします。

凍結セルの有効判定は、現行互換としてターン開始入口で固定します。ターン開始処理中に凍結期限が切れても、その同じターン開始中に後続特殊石が凍結対象セルを通過できるようにはしません。この挙動を変更する場合は、今回の turn-start parity 変更とは別仕様変更として扱います。

legacy marker に `markerId` が欠損している状態は移行互換として扱います。canonical cardState では、turn-start 対象になり得る marker は必ず canonical string `markerId` を持ちます。

### ターン開始中に生まれた新しい特殊石

ターン開始処理の途中で新しく生まれた特殊石や状態は、その同じターン開始処理では発動しません。

その石や状態が次に条件を満たすターン開始時から、登場順に従って処理します。

同じ色の火石、水石、草石、落雷石がそろった場合は、現在処理中の特殊石と、その個体が起こした復活・生成・反転をすべて完了してから森羅万象神へ融合します。融合後に次の特殊石へ進みます。開始時に固定した発動対象一覧へ新しい森羅万象神は追加せず、その4属性効果は次の所有者ターン開始から発動します。

## 複数特殊石の直列処理

特殊石が複数ある場合、同時に動いたり、同時に効果を発揮したりしてはいけません。

例:

1. 1体目の多動石が移動する。
2. その移動後に反転があれば反転する。
3. その石の持続減算や通常石化があれば処理する。
4. 1体目の演出と効果音が区切りまで完了する。
5. 2体目の特殊石の処理に進む。

この原則は、ターン開始で動く、発動する、減算する、通常石化するすべての特殊石・爆弾・継続状態に適用します。

## 1つの特殊石内の処理例

### ゾンビの意志

ゾンビの意志は、所有者ターン開始ごとに、まず隣接1マスの有効な空きへランダム移動します。移動先がない場合は現在位置に留まります。

移動が完了した後、移動後の位置を感染元として感染カウントを1進め、3回目なら隣接する敵通常石への噛みつきを解決します。移動と噛みつきは同じ特殊石の処理枠内で、移動演出、噛みつき演出、盤面結果の順に完了させます。

### 多動系

多動系の石は、順番が来た石ごとに移動します。

その石の移動先決定、移動演出、移動先ハイライト、移動後反転、反転による布石表示までを完了してから、次の石に進みます。

究極多動神のように1つの石が複数回移動する場合、その石の移動1回目、必要な反転、移動2回目、必要な反転までを1つの石の処理枠として完了させます。移動1回目だけ終えて別の特殊石へ割り込ませてはいけません。

### 破壊系

破壊龍、雷の意志、因果抹消神、狙撃の意志、究極破壊神、意志狩りの王などは、順番が来た石ごとに対象を決めます。

対象決定、赤ハイライト、固有演出、破壊または破壊回避、復活、幽体による無効化など、その破壊に関わる結果を完了してから次の石に進みます。

### 究極労働神

究極労働神は、順番が来た個体ごとに自壊確率を1ポイント上げ、その個体の更新後確率で抽選します。凍結中の個体は確率上昇も抽選も行いません。

抽選に外れた場合は、その石の吹き出し、布石5の加算、布石差分表示、効果音までを完了してから次の特殊石へ進みます。抽選に当たった場合は通常の破壊を試み、破壊回避・復活・救済などを含む結果を完了してから次へ進みます。破壊が防がれても、その個体は同じターンに布石を獲得しません。

複数の破壊系特殊石がいる場合、先に動いた石によって盤面が変わった後の状態を使って、次の石の対象を決めます。

### 生成系

繁殖の意志、救済の意志、増援の意志などで複数の石が生まれる場合、生成は1個ずつ見えるように再生します。

各生成ごとに、生成マスの決定、紫ハイライト、石の出現、生成後反転、布石表示を完了してから次の生成へ進みます。

### 森羅万象神

森羅万象神1体のターン開始効果は、火、水、草、雷の順に直列で処理します。各属性の対象決定と結果表示を完了してから次の属性へ進み、4属性すべてが終わってから次の特殊石へ進みます。

森羅万象神は4マスすべてが不可侵で凍結対象にならないため、凍結によって4属性効果を停止しません。

### 爆発系

時限爆弾、十字爆弾、クロス爆弾、逃亡石の移動不能爆発などは、1つの爆発を1つのまとまったアクションとして扱います。

範囲内の複数マスが同じ爆発で破壊される場合、同じ爆発として一括で見せてよいです。これは「複数の特殊石が同時に動く」こととは別です。

複数の爆弾が同じターン開始に起爆条件を満たす場合は、爆弾ごとの登場順で1個ずつ起爆します。

## 配置、反転、配置後効果

### 通常配置

通常配置では、次の順に見せます。

1. 石を置く。カード効果を伴わない通常手で通常石を置いた場合は、置いた1マスだけ青ハイライトを短く表示する。
2. 置いた石が特殊石になる場合は、配置直後から最終見た目で表示する。
3. 通常の挟み反転を順番に再生する。
4. 配置後に発動するカード効果を再生する。
5. 同じ色の火石、水石、草石、落雷石がそろっていれば森羅万象神へ融合する。
6. 布石加算と差分表示を出す。

`瞬間多動` / `十字爆弾` / `クロス爆弾` / `金` / `銀` / `虹` のような配置時効果は、この手順4の中で完結します。特殊石の持続ターン管理や次ターン以降のターン開始ライフサイクルには入りません。

カード個別仕様で「配置時に先に発動する」と明記された効果は、そのカードの仕様を優先します。ただし、その場合でも、効果内の移動、破壊、生成、反転は順番に見せます。

### 追加配置

二連投石、三連投石、四連投石、無限投石、最後の切り札など、同じ手番で複数回配置する効果は、新しい手番ではなく、同一手番内のサブ配置として扱います。

1回目の配置処理をすべて完了してから2回目へ進みます。各サブ配置では、通常配置と同じく配置、反転、配置時効果、布石加算、終了判定を行います。

追加配置はカード効果由来の配置として扱い、着地マスの一時ハイライトは青ではなく紫にします。

追加配置の途中でターン開始効果、通常ドロー、カード使用回数リセット、手札破壊回数リセットを再実行しません。追加配置中に新たなカード使用や手札破壊はできません。

無限投石は、合法手がなくなった時点で追加配置を終了します。

最後の切り札の3回自由配置も同一手番内のサブ配置です。途中で空きマスがなくなった場合は、残り配置を破棄して追加配置を終了します。

### 対象選択型カード

対象選択型カードは、対象選択が確定した時点で効果を解決します。

対象選択後は、その効果の盤面変化、演出、効果音、手札変化、布石変化、手番終了が完了するまで、次の入力を受け付けません。

カード効果、追加配置、復活、生成などのまとまった盤面処理が完了するたび、森羅万象神の融合条件を再判定します。出現可能な2×2がないため保留された素材は、この再判定まで盤面に残ります。

ここで禁止する次入力には、盤面クリック、カード選択、カード使用、手札破壊、パス、overlay 上の選択確定を含みます。

罠の意志、交換の意志など、対象選択で手番が終わるカードは、効果が完了した後に通常配置を行わず手番交代へ進みます。

強風の意志、浮力、超浮力、重力、超重力、超引力は対象選択して効果を解決した後、同じ手番内で通常配置へ進みます。通常配置が完了してから手番交代へ進みます。

## 同時に見せてよいもの、いけないもの

### 同時に見せてよいもの

- 1つの爆発による範囲破壊。
- 1つの盤面縮小で同時に穴化される複数マス。
- 1つの盤面拡張で同時に追加される複数マス。
- 1つのラウンドボーナスで黒白両方の布石が増える表示。
- 1つの効果に含まれる複数マスのハイライト。

これらは「1つのアクションの範囲表示」です。

### 同時に見せてはいけないもの

- 複数の特殊石が同時に移動する。
- 複数の特殊石が同時に破壊対象を決める。
- 複数の特殊石が同時に生成する。
- 多動石の移動中に別の特殊石の効果が割り込む。
- 破壊演出が終わる前に、別の特殊石の移動が始まる。
- 対象選択型カードの解決途中に、次の配置や手札操作が可能になる。

## 終了判定と手番交代

終了判定は、配置、反転、カード効果、特殊石効果、布石加算、通常石化など、その手番で起きるべき処理がすべて完了した後に行います。

終局条件は両者連続パスのみです。盤面が埋まっただけでは終局しません。片側の石数が0になっただけでも即時終局しません。自石0で通常合法手もカード使用もない場合は、通常のパス処理に従い、両者連続パスで終局します。

合法手0かつ使用可能カード0の場合は、パス以外の行動がないため、パスボタンの操作を待たずに自動または強制パスで進めます。使用可能カードがある場合や未解決の対象選択がある場合は、自動パスしてはいけません。

この自動または強制パスが成立した場合、UI は画面中央に `黒 : 自動パス` または `白 : 自動パス` と `合法手と使用可能カードがありません。` を3秒表示し、フェードイン/フェードアウトで消します。これは表示専用の通知であり、ローカル対戦とネット対戦の双方で同じ成立済みパスを同じ手番色として表示します。

終局条件を満たした場合は、手番交代より終局表示を優先します。

手番交代は、盤面再生と入力ロックが解けるべきタイミングが一致してから行います。次プレイヤーの入力可能表示だけが先に出て、前手番の演出がまだ残っている状態にしてはいけません。

## ネット対戦で特に守ること

ネット対戦の結果一致と再接続時の最終状態は共通ルール正本に従います。

ターン進行としては、通信遅延があっても、確定した順番の再生が終わる前に次の入力や手番表示を先行させないことを守ります。

選択完了で結果が確定し、そのまま使用者の手番が続く効果は、通信待ち中でも使用者側の盤面表示を確定後の状態へ直ちに合わせます。守る意志の完全保護マークのような石上表示が相手側にだけ先行して見える状態にしてはいけません。
