# カードリバーシ 正本インデックス

このフォルダは、カードリバーシの「あるべき挙動」をプレイヤー視点で記録する正本です。

実装が今どうなっているか、どのファイルを読んでいるか、どの関数が呼ばれているかではなく、対局中に何が起こるべきかを基準にします。別ゲームエンジンへ移行する場合も、この正本を満たすことを目標にします。

## 文書

- [共通ルール正本.md](./共通ルール正本.md): 破壊、反転、回避、保護、幽体、ハイライト、ネット対戦時の共通原則。
- [ターン進行正本.md](./ターン進行正本.md): 1手番内の処理順、特殊石の発動順、アクションとアニメーションの直列再生。
- [カード仕様正本.md](./カード仕様正本.md): 各カードの効果、成立条件、失敗条件、持続、対象。
- [演出正本.md](./演出正本.md): 盤面演出、ハイライト、石移動、カード固有演出、ネット対戦での見え方。
- [効果音対応表.md](./効果音対応表.md): 効果音ファイルと、鳴るべき盤面・鳴らないべき盤面の対応。
- [正本差分監査.md](./正本差分監査.md): 正本 v1 と現挙動の差分、信頼度、根拠、次アクションを管理する監査台帳。仕様正本そのものではない。

## 責務分担

- 共通ルールには、全カードで使う用語、状態、ランダム決定、ネット対戦の結果一致を書く。
- ターン進行には、1手番内の処理順、入力再開、複数特殊石の発動順を書く。
- カード仕様には、カードごとの効果と成立条件を書く。演出や音は原則として書かない。
- 演出には、見た目、ハイライトの出し方、石移動の見せ方、カード固有アニメを書く。
- 効果音対応表には、音ファイルと再生条件だけを書く。

## 正本としての書き方

- 「このカードはこう振る舞うべき」と書く。
- プレイヤーに見える効果、状態、音、演出、失敗条件を優先して書く。
- 実装ファイル名、関数名、内部イベント名、内部データ構造を正本の根拠にしない。
- ランダム効果は、誰の画面でも同じ結果になるべき対象決定として書く。
- ネット対戦、CPU戦、ローカル対戦で最終結果が変わる場合は、別仕様として明記する。
- 仕様未決定の挙動は、実装に合わせて曖昧にせず「未決定」と書く。
- 同じ原則を複数文書へ書き写さず、責務を持つ文書へ寄せて参照する。

## 更新ルール

カード効果、演出、効果音、ネット対戦で見える挙動を変えるときは、まずこの正本の該当箇所を更新します。

正本と実装が食い違う場合、原則として正本を満たすように実装を直します。ただし正本自体が古い、または仕様判断が必要な場合は、先に正本を修正してから実装します。
