# 演出正本

この文書は、カード効果や盤面状態がどのように見えるべきかを定義します。

1手番内の処理順と複数特殊石の発動順はターン進行正本、音は効果音対応表、ハイライト色の意味は共通ルール正本に従います。

## 再生原則

- 盤面上で起きた効果は、ターン進行正本の順番どおりに再生します。
- 特殊石は、配置直後から最終見た目で表示します。後から遅れて通常石から特殊石へ差し替わる見た目は禁止です。
- 手置き演出がある着手では、盤面クリック直後に確定石を先出ししません。手が着手点へ到達して石を置く接触タイミングで完成状態の石を表示し、追加待機を挟まず後続の配置・反転演出へ進みます。
- 反転は、最終色へ切り替えたうえでフリップモーションを再生します。
- 通常の反転フリップモーションは約0.46秒で完了する短めのテンポを基準にします。
- 誘惑、継承、復活、意志の喪失、持続切れの通常石化など、物理的な裏返りではない変化はクロスフェードを優先します。
- 通常ドロー演出の手モーションは約0.56秒、手置き演出の手モーションは約0.44秒で完了する短めのテンポを基準にします。手置き演出の手は画面の上下端ではなく配置する側の手札カード付近から盤面へ伸び、近づく間は透明度フェードイン、手札側へ戻り始めてから約0.07秒で透明度フェードアウトを完了し、そのまま手札側へ退避します。
- 手番が自分側へ来たときは `Your Turn`、相手側へ来たときは `Enemy Turn` の短いトーストを盤面下フレーム右端に15秒表示し、その後フェードアウトします。トースト色は自分/相手ではなく手番の実プレイヤー色に従い、黒番は黒基調、白番は白基調にします。
- 盤面セル間を進む狙撃弾、吸い込み、ブレス、光線、雷、噛みつきは、拡張盤面をスクロールしていても攻撃元と対象を論理上の始終点にします。現在の盤面表示領域から外れて見えていない区間は描かず、対象が見えている場合は対象まで到達してから破壊・反転・変化を見せます。

ゲームコアは確定した意味順を持つ ordered presentation events を生成します。UI はこの順序から逆算して特殊石順を推測してはならず、snapshot 差分や `cause` 名だけで複数特殊石をまとめてはいけません。

`sequenceIndex` は全 presentation event の意味順、`actionId` は1つの特殊石・爆弾・ターン開始アンカーの直列境界、`effectBlockId` は1回の爆発や1回の破壊バッチなど同時表示を許す一括効果境界、`phase` は実際に UI が同時再生する単位とします。

異なる非 null `actionId` を持つイベントは同じ `phase` に入れません。1個の時限爆弾による範囲破壊は同じ `effectBlockId` 内で同じ `phase` にできますが、別の時限爆弾は `cause` が同じでも別 `actionId` として後続 `phase` にします。

破壊対象の石は `DESTROY` playback が所有してから消します。canonical state が先に空マスになっていても、presentation playback がある場合は final board diff で対象石を先に消しません。

## ハイライト

| 色 | 使う場面 | 補足 |
| --- | --- | --- |
| 赤 | 共通ルール正本の赤ハイライト対象 | 破壊対象になったことが分かる時間だけ表示する。 |
| 紫 | 共通ルール正本の紫ハイライト対象 | 破壊以外の盤面効果が起きたマスに、効果の見え方を妨げない濃さで表示する。 |

封鎖の意志と凍結の意志は、専用の赤バツ表示や氷表示を主表示にします。追加の一時ハイライトは必須ではありません。

## 移動演出

| 種類 | 見た目 | 対象例 |
| --- | --- | --- |
| 滑らかな1マス移動 | 石が元マスから移動先へ滑る。移動距離ではなく固定の見やすい時間で再生する。 | 多動の意志、逃げる意志、ロボット掃除機、極悪多動魔 |
| 滑らかな長距離移動 | 石が方向性を持って移動する。経路破壊がある場合は、衝突位置に合わせて破壊を見せる。 | 強風の意志、浮力、重力、超浮力、超重力、超引力、究極反転龍、究極破壊神、意志狩りの王 |
| 入替移動 | 2つの石が入れ替わったことが分かるよう、両方のマスを紫ハイライトする。 | 入替の意志 |
| 即時テレポート | 移動軌跡を描かず、移動先へ即時出現する。移動先は紫ハイライトする。 | テレポート、マステレポート |

## 森羅万象神

融合演出は、素材となる火石、水石、草石、落雷石の消費、出現場所にある石の除去、2×2を覆う大型石の出現の順に再生します。4マスを4個の独立した石画像として見せず、黒用または白用の大型石画像1枚を2×2全体へ表示します。

森羅万象神には完全保護、反転保護、不可侵の石上バッジを表示しません。代わりに、火・水・草・雷を感じられる多色のオーラを2×2全体の周囲へ放って不可侵を表現し、石画像や盤面の読みやすさを損なわない強さでゆっくり明滅させます。動きを減らす設定では明滅を止め、静止したオーラを残します。

ターン開始の属性効果は火、水、草、雷の順に再生し、1つ前の着弾と盤面結果を確定してから次を始めます。軌道の始点は2×2の中心とし、盤面回転や表示範囲にかかわらず同じ論理位置から見えるようにします。

森羅万象神の石情報詳細には専用のカード風背景を使います。この背景はカード画像ではなく、カード一覧、デッキ、手札、ドロー演出には表示しません。

## カード固有演出

| カード/効果 | 演出として必要なこと |
| --- | --- |
| 特殊カード共通 | 顕現石は盤面全体で同時に1個までとし、いずれかの顕現石が盤面にある間は両者とも特殊カードを使用できない。使用確定時は、カード使用演出の phase で画面全体を暗転フェードし、固有セリフをやや小さめのノベルゲーム風テキストとして1文字ずつ表示し、その特殊カードの立ち絵を表示する。句読点では短く間を置き、パッと全文を出さない。カード面も `assets/images/special-cards/characters/` 配下の立ち絵を主役として表示する。カード使用と同時に、その特殊カードに対応する専用背景を通常背景より優先して表示する。対応する顕現石が消えたら、全顕現石共通の2秒終了演出として、顕現石を同色の通常石へ戻す見た目の切替と同時に画面全体の暗転を開始し、最大60%程度まで前半でフェードイン、後半でフェードアウトして通常状態へ戻す。同じ2秒間で専用BGMを前半に早めにフェードアウトし、元のBGMを後半からフェードインして中央に短い無音寄りの間を作る。この2秒間は他の盤面演出や効果音を同時再生せず、盤面・手札・パスなどの操作をブロックする。顕現石のオーラ残光、専用背景の名残、専用BGMの遅延解除とは重複させない。終了文言は表示しない。カード固有の選択UIや次の配置入力は、この共通演出が終わってから表示する。暗転・固有セリフ演出後には、盤面中央に領域名を含まない半透明背景の短期サマリーを3.0秒表示し、0.5秒でフェードアウトする。クリックまたはタップで即時フェードアウトできる。盤界の執行者と理論の化身は両者に同じ短期サマリーを表示し、盤理の観測者は使った側には表示せず使われた側にだけ表示する。顕現石は共通して所有者色のオーラを表示し、黒側は黒寄り、白側は白寄りに発光する。顕現石の次配置予約が成立した時点から、左側の戦況パネルと石情報パネルの下に領域名つきの顕現効果パネルを表示し、実際に顕現石が盤面へ置かれた後も継続する。予約中は残りターンを出さず、盤面上に顕現石がある間はパネル見出しに `執行領域　残りNターン` / `観測領域　残りNターン` / `理論領域　残りNターン` の形式で残りターンを併記する。 |
| 理論の化身 | 顕現石の配置直後、または所有者の通常配置後に理論数字マスから特殊石が出現するときは、候補理論マスを2.5秒の19ステップ固定ルーレットで点滅させる。マス切り替えは候補数に依存せず、ルーレット開始効果音内の単音タイミングに合わせる。最終的に選ばれるマスは headless の抽選結果に必ず一致させ、停止後は確定マスをダーク発光させながら特殊石を約2秒かけてフェードインさせる。ローカルとネット対戦の両者で同じ playback event を再生し、UI 側が抽選結果を決めてはいけない。顕現効果パネルには `理論領域`、`所有者: カード使用不可`、`空きマスを理論数字マス化`、`所有者の通常配置後に特殊石が出現` を表示する。 |
| 盤界の執行者 | 固有セリフは「盤界の名において執行する。因果を歪ませる変数に、一切の例外を認めない。」。使用確定時は特殊カード共通の暗転演出を再生し、`assets/images/special-cards/characters/board_executor.png` の立ち絵を表示する。暗転演出が終わってから、使用効果による特殊石の穴化を再生する。その後、次の自石配置で4ターン持続の盤界の執行者顕現石を置く。顕現中BGMは特殊カード使用音の3秒無音が終わってから `assets/audio/bgm/manifest-stones/執行の道-bpm150.mp3` を再生し、盤界の執行者が消えたら通常BGMへ戻る。顕現効果パネルには `執行領域`、`両者: カード使用不可`、`両者: 手札が多いほど布石を失う`、黒白それぞれの `手札N枚 → 次開始 -X` を表示し、Xは現在手札枚数から即時更新する。 |
| 究極労働神 | 配置時の固有吹き出しと自壊確率バッジは表示しない。収入成立時は石の近くに「もっと稼がないと……」を基調にした5候補を表示する。実際に自壊した時は完全に心が折れた5候補、相手など外部効果で実際に破壊された時は、前世でお金が足りず大切な人を救えなかった未練を想起させる5候補を表示する。完全保護、幽体、破壊回避、増殖、復活、生きる意志などで破壊が防がれた場合は自壊・外部破壊の台詞を表示せず、成立した防御・復活側の演出を優先する。 |
| 盤理の観測者 | 固有セリフは「我が観測をもって、悲しき輪廻に新たな一手を示そう」。暗転演出後に相手手札選択UIを表示し、カードを奪ってから観測者を顕現させる配置へ進む。選択UIには「観測済みの相手手札はコスト+5。選択したカードは0コストで獲得。」という警告風の説明を表示する。専用背景はカード使用と同時に開始する。専用BGMは特殊カード使用音の3秒無音が終わってから開始し、観測者が消えたら通常BGMへ戻る。顕現効果パネルには `観測領域`、`所有者: 相手手札を常時観測`、`観測済みカード: コスト +5` を表示する。返済で布石を失った場合は、布石量 UI の上に `観測の代償 -N` の HUD ポップアップを表示する。 |
| 破壊龍 | 破壊対象を決定したとき、対象マスを赤ハイライトし、破壊龍固有の火を噴くアニメを再生する。対象が幽体や回避で消えない場合でも、狙われた事実は見えるようにする。 |
| 狙撃の意志 | 命中対象を赤ハイライトし、破壊が起きたことを明確に見せる。複数の狙撃石が発動する場合は、命中ごとに分かる順で見せる。 |
| 雷の意志 | ランダムに選ばれた敵石が、盤面上のどこから狙われたか分かるように赤ハイライトする。破壊対象がない場合は過剰な演出を出さない。 |
| 因果抹消神 | ランダムに選ばれた敵石へ因果抹消神石から黒いビームを放ち、その後に因果抹消と同じ穴化演出で見せる。選ばれたマスが穴化できず不発になった場合は過剰な演出を出さない。 |
| 多動の意志 | ターン開始移動は滑らかに行う。移動先マスは紫ハイライトする。瞬間移動に見せない。 |
| 瞬間多動 | 3回のランダム移動は、1回ずつ順番に見せる。各移動後に反転がある場合は、移動と反転の順序を崩さない。 |
| テレポート | 滑らかな石移動ではなく、対象石が移動先へきっぱり出現するテレポート演出にする。移動経路は見せない。 |
| マステレポート | 石は即時テレポートで外側へ出現し、元マスは穴になったことを明確に見せる。元マス穴化は破壊演出にしない。 |
| 超引力 | 石を選んだ後の引き寄せ先選択中は、候補マスへのホバーで移動経路を表示する。2つの最短経路候補が両方成立する場合は、両方の経路を表示する。 |
| 入替の意志 | 1つ目の選択中はそのマスを紫ハイライトし、2つ目確定時は両方のマスを紫ハイライトする。 |
| 罠の意志 | 罠石は発動または不発で公開されるまで、設置者を含む両者に通常石として見える。選択直後に罠見た目へ切り替えない。 |
| 毒殺の意志 | 毒マスは通常マスと見分けられる紫系の毒々しい見た目にする。毒マス自体の持続ターン数は毒マスの左上の角に表示する。毒状態の石は元の石色と種類を判別できる程度に、石全体へ弱い紫色を重ねる。石のど真ん中に、既存の石タイマーを流用しない毒専用の紫色三角形マーカーを置き、毒による破壊までの残りターン数を表示する。毒付与と完全保護による毒解除は紫ハイライト、致死カウント到達時の破壊試行は赤ハイライトで示す。破壊回避などで石が残る場合も元マスの赤ハイライトを省略しない。 |
| 火の意志 | 灼熱マスは毒マスに近い構造で、通常マスと見分けられる赤〜橙系の熱を帯びた見た目にする。灼熱マスが成立するときは、発動元の火石から対象マスへ赤〜橙色の炎ビームを飛ばし、着弾後に灼熱マスを表示する。生成音は着弾して灼熱マスが見えるタイミングで、成立した1マスにつき1回鳴らす。灼熱マス自体の残りターン数はマスの左上、石が居座れる残りターン数は石の中央に表示する。毒状態と灼熱カウントが同じ石へ重なった場合は、毒表示を中央左、灼熱表示を中央右へ少しずらし、両方を同時に読めるようにする。灼熱による破壊試行は赤ハイライトで示し、破壊回避などで石が残る場合も省略しない。火石は黒白それぞれ `assets/images/special-stones/fire-will-black.png` / `assets/images/special-stones/fire-will-white.png` の専用画像で表示する。候補マスがなく灼熱マスが成立しない場合は、炎ビームも生成音も出さない。 |
| 水の意志 | 治癒マスは灼熱マスと同じ構造の青色版として、通常マスと見分けられる濃淡の青と水面のような発光で表示する。残りターン数はマスの左上に表示する。治癒マスが成立するときは、発動元の水石から対象マスへ青〜水色の水ビームを飛ばし、着弾後に治癒マスを表示する。生成音は着弾して治癒マスが見えるタイミングで、成立した1マスにつき1回鳴らす。水石は黒白それぞれ `assets/images/special-stones/water-will-black.png` / `assets/images/special-stones/water-will-white.png` の専用画像で表示する。治癒による特殊石本体の持続ターン加算は、既存の持続ターン変化表示で実値の増加が読めるようにする。候補マスがなく治癒マスが成立しない場合は、水ビームも生成音も出さない。 |
| 草の意志 | 種が成立するときは、発動元の草石から対象マスへ緑色の草ビームを飛ばし、着弾後に種マスを表示する。種配置音は種まきの意志と同じ音を着弾時に、成立した種1マスにつき1回鳴らす。配置直後と所有者ターン開始時のどちらの播種にも同じ演出を使う。候補マスがなく種が成立しない場合は、草ビームも種配置音も出さない。 |
| 幽霊の意志 | 反転を無効化したときは紫、破壊を無効化したときは赤で短く示す。誘惑・捕獲など対象条件を満たす反転・破壊以外の効果は通常演出で成立する。交換の意志は通常石のみ対象のため幽体を選べない。 |
| 犠牲の意志 | 相手の通常カードを無効化する場合、まず通常のカード使用ポップアップを見せる。その後、ポップアップされた使用カードを犠牲石の方向へ吸い込まれるように縮小・フェード移動させ、カードが犠牲石に取り込まれた直後に犠牲石の既存赤ハイライト破壊演出を再生する。 |
| 避ける意志 | 回避成功時は移動と残回数減少が分かるように見せる。回避失敗時は、消滅または破壊として見せる。 |
| 復活の意志 | 反転で復活する場合は、敵色への一時フリップを強く見せすぎず、元色へ戻ったことを分かるようにする。破壊で復活する場合は、破壊対象になったことと盤面に残ったことを両方見せる。復活可能回数は持続ターン表示ではなく、石の中央左側にピンクのハートバッジで表示する。 |
| ゾンビの意志 | 感染成立時は、攻撃元の屍石から対象へ黒紫の影が這い、対象を挟む半透明の牙が閉じた後に屍石へ変化させる。複数の屍石は登場順に1体ずつ見せ、噛みつき効果音は同一感染バッチで1回だけ鳴らす。感染対象がない不発時は噛みつき演出を出さない。 |
| 生きる意志 | 付与中は黄色いオーラを表示する。失われて復活する場合は、失われた後に戻る順で見せる。因果抹消/盤面縮小/盤面縮小神/マステレポートのセル消滅では消費・復活を見せない。反転で復活する場合は、相手色へ変わった直後に元色へ戻るように見せる。復活後に反転がある場合は、復活を見せてから反転を順番に見せる。 |
| 増殖の意志 | 破壊を無効化して増殖した場合、元マスの赤ハイライト後、増殖先の生成を見せる。 |
| 繁殖の意志 | 生成は同時に見せず、発生した石ごとに順番が分かるように見せる。生成マスは紫ハイライトする。 |
| 複製の意志 | 複製元から複製先へ石が移って出現したように見せる。複製元が消えたようには見せない。 |
| 救済の意志 | 複数救済は1個ずつ順番に生成して見せる。各生成マスは紫ハイライトする。 |
| 平等の意志 | 石生成・反転演出は行わず、布石UIの増減表示で解決する。 |
| 増援の意志 | 生成される1個の石を、カード使用演出の後に明確に出現させる。生成マスは紫ハイライトする。カード選択中は候補マスを薄く表示し、通常の合法手表示は重ねない。 |
| 援軍の意志 | 最大3個の生成を1個ずつ順番に見せる。各生成マスは紫ハイライトし、各生成後の反転も順番が分かるように見せる。カード選択中は候補マスを薄く表示し、通常の合法手表示は重ねない。 |
| 十字爆弾 / クロス爆弾 / 時限爆弾 | 爆弾本体の起爆と範囲爆破を同じ破壊系の流れで見せる。爆破対象マスは赤ハイライトする。 |
| 逃げる意志 | 移動先がなく爆発する場合、周囲1マス爆破と自身消滅を一括の爆発として見せる。 |
| ロボット掃除機 | 移動後に吸い込む。移動先で通常反転は起こさない。吸い込み対象は破壊とは違う吸い込みとして見せる。 |
| 悪食の意志 | 捕食で敵石に進入する場合、移動と捕食が同じ意味に見えるようにする。飢えによる消滅は通常破壊ではなく悪食の終了として見せる。 |
| 意志狩りの王 | 対象の敵石を狙い、そのマスへ移動しながら破壊する。破壊回避された場合は、元対象マスと回避先の意味が混ざらないように見せる。 |
| 究極多動神 | 直線移動を2回に分けて見せる。2マス以上の移動では途中の石を飛び越えることが分かるようにする。 |
| 盤面拡張 / 盤面拡張神 | 選択中の拡張候補には、拡張先方向が分かる外向き矢印を方向ごとに重ねる。同じマスから複数方向へ拡張できる場合は、各矢印を個別に選べるようにする。新しいマスが盤面に追加された直後に、追加範囲が分かるように見せる。拡張後もブラウザ標準の縦横スクロールバーは表示せず、盤面フレームの画面上の中心位置と既存セルの位置・縮尺を維持する。 |
| 盤面縮小 / 盤面縮小神 | 選択中のマスや辺を紫ハイライトし、盤面縮小で1つ目以降を選んだ後の次候補マスと、盤面縮小神で角を選んだ後の2つ目候補マスには縮小方向の矢印も重ねる。盤面縮小神では矢印候補ごとの縮小予定辺マス列を既存の合法手表示と同じ青マスで見せる。確定後は穴画像を基調に、盤面縮小由来の黒いフレーム縁と内側エッジを重ね、配置・移動・反転経路に使えない穴マスであることが通常盤面でも分かるように表示する。 |
| 因果抹消 | 対象マスを石ごと破壊して穴にする。石破壊とマス消失が両方分かるようにする。 |
| 因果再生 | 選択中は因果抹消系・盤面縮小系を含む穴マスだけに合法手表示に近い候補マークを重ねる。確定クリック後は候補マークを消し、再生された通常マスを紫ハイライトする。 |
| 凍結の意志 | 凍結中は氷表示と残りターンを維持する。凍結された石は動けず、反転や破壊を受けないことが見た目で分かるようにする。 |
| 運命の意志 | 操作側には相手ターンを操作中であることを表示し、被操作側には入力不能で待機中であることを表示する。双方で効果中表示が欠けてはいけない。 |

## ネット対戦で特に守ること

ネット対戦の結果一致は共通ルール正本、入力再開はターン進行正本に従います。

ネット対戦でも、server が受理した演出フレームはローカル対戦と同じ順番で全て再生する。再接続後や終盤で演出が溜まっている場合も、アクティブな room 内では最新盤面へ演出を飛ばして同期完了扱いにしない。表示が追いつくまで入力は待機し、盤面は visual timeline が進めた状態を描画する。

自分の通常配置を送信した直後だけ、選択マスに水色の送信中リングをローカル表示してよい。これは通信待ちを示す非確定の UI であり、石・反転・盤面状態・効果音・`events[]` ではない。相手や観戦者へ配信せず、server 応答または同じ操作IDを含む受信、拒否、退出、session 切替で消す。確定演出の再生順や入力再開条件を変えてはいけない。

終局時は、最終演出フレームの visual settlement が完了した後にリザルトを表示する。canonical snapshot の終局判定や通信応答が先に届いても、演出より先にリザルトを表示しない。visual settlement の timeout、reset、失敗を正常完了として扱わず、未完了の演出ロックを表示側から強制解除しない。

自分以外の対局者または観戦者の入室/退出を受信したときは、横軸は画面中央、縦軸は盤面中央より少し下かつ下側の布石UIより上の位置に中型HUDとして `名前さんが入室しました` または `名前さんが退出しました` を約4秒表示し、その後フェードアウトします。ネット対戦設定パネルを開いている間も、そのパネルより前面に表示します。これは表示専用で、盤面演出、入力ロック、確定済みの `events[]` 再生順には影響させません。

演出面では、ライブ再生中の使用者側と相手側で、ハイライト、移動、反転、破壊、生成、通常石化の意味が食い違わないことを守ります。
