# 演出正本

この文書は、カード効果や盤面状態がどのように見えるべきかを定義します。

1手番内の処理順と複数特殊石の発動順はターン進行正本、音は効果音対応表、ハイライト色の意味は共通ルール正本に従います。

## 再生原則

- 盤面上で起きた効果は、ターン進行正本の順番どおりに再生します。
- 特殊石は、配置直後から最終見た目で表示します。後から遅れて通常石から特殊石へ差し替わる見た目は禁止です。
- 反転は、最終色へ切り替えたうえでフリップモーションを再生します。
- 通常の反転フリップモーションは約0.46秒で完了する短めのテンポを基準にします。
- 誘惑、継承、復活、意志の喪失、持続切れの通常石化など、物理的な裏返りではない変化はクロスフェードを優先します。
- 通常ドロー演出の手モーションは約0.56秒、手置き演出の手モーションは約0.44秒で完了する短めのテンポを基準にします。

## ハイライト

| 色 | 使う場面 | 補足 |
| --- | --- | --- |
| 赤 | 共通ルール正本の赤ハイライト対象 | 破壊対象になったことが分かる時間だけ表示する。 |
| 紫 | 共通ルール正本の紫ハイライト対象 | 破壊以外の盤面効果が起きたマスに、効果の見え方を妨げない濃さで表示する。 |

封鎖の意志と凍結の意志は、専用の赤バツ表示や氷表示を主表示にします。追加の一時ハイライトは必須ではありません。

## 移動演出

| 種類 | 見た目 | 対象例 |
| --- | --- | --- |
| 滑らかな1マス移動 | 石が元マスから移動先へ滑る。移動距離ではなく固定の見やすい時間で再生する。 | 多動の意志、逃げる意志、ロボット掃除機、極悪多動魔 |
| 滑らかな長距離移動 | 石が方向性を持って移動する。経路破壊がある場合は、衝突位置に合わせて破壊を見せる。 | 強風の意志、浮力、重力、超浮力、超重力、超引力、究極反転龍、究極破壊神、意志狩りの王 |
| 入替移動 | 2つの石が入れ替わったことが分かるよう、両方のマスを紫ハイライトする。 | 入替の意志 |
| 即時テレポート | 移動軌跡を描かず、移動先へ即時出現する。移動先は紫ハイライトする。 | テレポート、マステレポート |

## カード固有演出

| カード/効果 | 演出として必要なこと |
| --- | --- |
| 特殊カード共通 | 顕現石は盤面全体で同時に1個までとし、いずれかの顕現石が盤面にある間は両者とも特殊カードを使用できない。使用確定時は、カード使用演出の phase で画面全体を暗転フェードし、固有セリフをやや小さめのノベルゲーム風テキストとして1文字ずつ表示し、その特殊カードの立ち絵を表示する。句読点では短く間を置き、パッと全文を出さない。カード面も `assets/images/special-cards/characters/` 配下の立ち絵を主役として表示する。カード使用と同時に、その特殊カードに対応する専用背景を通常背景より優先して表示し、対応する顕現石が消えたら通常背景へ戻す。カード固有の選択UIや次の配置入力は、この共通演出が終わってから表示する。顕現石は共通して所有者色のオーラを表示し、黒側は黒寄り、白側は白寄りに発光する。顕現石が盤面にある間だけ、左側の効果ログ下に領域名つきの顕現効果パネルを表示する。残りターンは盤面上の顕現石カウントに任せ、パネルには出さない。 |
| 理論の化身 | 顕現石の配置直後、または自分ターン開始時に理論数字マスから特殊石が出現するときは、候補理論マスを2.5秒の19ステップ固定ルーレットで点滅させる。マス切り替えは候補数に依存せず、ルーレット開始効果音内の単音タイミングに合わせる。最終的に選ばれるマスは headless の抽選結果に必ず一致させ、停止後は確定マスをダーク発光させながら特殊石を約2秒かけてフェードインさせる。ローカルとネット対戦の両者で同じ playback event を再生し、UI 側が抽選結果を決めてはいけない。顕現効果パネルには `理論領域`、`所有者: 石配置・カード使用不可`、`空きマスを理論数字マス化`、`ランダムで選ばれた理論数字マスと同コストの特殊石が出現` を表示する。 |
| 盤界の執行者 | 固有セリフは「盤界の名において執行する。彷徨える魂よ、今ここに収束せよ」。使用確定時は特殊カード共通の暗転演出を再生し、`assets/images/special-cards/characters/board_executor.png` の立ち絵を表示する。暗転演出が終わってから、使用効果による特殊石の穴化を再生する。その後、次の自石配置で4ターン持続の盤界の執行者顕現石を置く。専用音声が用意されるまでは、顕現中BGMは盤理の観測者用BGMを暫定利用する。顕現効果パネルには `執行領域`、`所有者: 反転布石 x2`、`両者: カード使用不可`、`両者: 手札が多いほど布石を失う`、黒白それぞれの `手札N枚 → 次開始 -X` を表示し、Xは現在手札枚数から即時更新する。 |
| 盤理の観測者 | 固有セリフは「我が観測をもって、悲しき輪廻に新たな一手を示そう」。暗転演出後に相手手札選択UIを表示し、カードを奪ってから観測者を顕現させる配置へ進む。選択UIには「観測済みの相手手札はコスト+5。選択したカードは0コストで獲得。」という警告風の説明を表示する。専用背景はカード使用と同時に開始する。専用BGMは特殊カード使用音の3秒無音が終わってから開始し、観測者が消えたら通常BGMへ戻る。顕現効果パネルには `観測領域`、`所有者: 相手手札を常時観測`、`観測済みカード: コスト +5` を表示する。 |
| 破壊龍 | 破壊対象を決定したとき、対象マスを赤ハイライトし、破壊龍固有の火を噴くアニメを再生する。対象が幽体や回避で消えない場合でも、狙われた事実は見えるようにする。 |
| 狙撃の意志 | 命中対象を赤ハイライトし、破壊が起きたことを明確に見せる。複数の狙撃石が発動する場合は、命中ごとに分かる順で見せる。 |
| 落雷 | ランダムに選ばれた敵石が、盤面上のどこから狙われたか分かるように赤ハイライトする。破壊対象がない場合は過剰な演出を出さない。 |
| 多動の意志 | ターン開始移動は滑らかに行う。移動先マスは紫ハイライトする。瞬間移動に見せない。 |
| 瞬間多動 | 3回のランダム移動は、1回ずつ順番に見せる。各移動後に反転がある場合は、移動と反転の順序を崩さない。 |
| テレポート | 滑らかな石移動ではなく、対象石が移動先へきっぱり出現するテレポート演出にする。移動経路は見せない。 |
| マステレポート | 石は即時テレポートで外側へ出現し、元マスは穴になったことを明確に見せる。元マス穴化は破壊演出にしない。 |
| 超引力 | 石を選んだ後の引き寄せ先選択中は、候補マスへのホバーで移動経路を表示する。2つの最短経路候補が両方成立する場合は、両方の経路を表示する。 |
| 入替の意志 | 1つ目の選択中はそのマスを紫ハイライトし、2つ目確定時は両方のマスを紫ハイライトする。 |
| 罠の意志 | 罠石は発動または不発で公開されるまで、設置者を含む両者に通常石として見える。選択直後に罠見た目へ切り替えない。 |
| 幽霊の意志 | 反転・誘惑を無効化したときは紫、破壊・捕獲を無効化したときは赤で短く示す。幽体が対象になったが受けなかったことを見落とさせない。 |
| 避ける意志 | 回避成功時は移動と残回数減少が分かるように見せる。回避失敗時は、消滅または破壊として見せる。 |
| 復活の意志 | 反転で復活する場合は、敵色への一時フリップを強く見せすぎず、元色へ戻ったことを分かるようにする。破壊で復活する場合は、破壊対象になったことと盤面に残ったことを両方見せる。 |
| 生きる意志 | 付与中は黄色いオーラを表示する。失われて復活する場合は、失われた後に戻る順で見せる。因果抹消/盤面縮小/盤面縮小神/マステレポートのセル消滅では消費・復活を見せない。反転で復活する場合は、相手色へ変わった直後に元色へ戻るように見せる。 |
| 増殖の意志 | 破壊を無効化して増殖した場合、元マスの赤ハイライト後、増殖先の生成を見せる。 |
| 繁殖の意志 | 生成は同時に見せず、発生した石ごとに順番が分かるように見せる。生成マスは紫ハイライトする。 |
| 複製の意志 | 複製元から複製先へ石が移って出現したように見せる。複製元が消えたようには見せない。 |
| 救済の意志 | 複数救済は1個ずつ順番に生成して見せる。各生成マスは紫ハイライトする。 |
| 平等の意志 | 3個の生成は1個ずつ順番に見せる。各生成マスは紫ハイライトする。 |
| 増援の意志 | 生成される1個の石を、カード使用演出の後に明確に出現させる。生成マスは紫ハイライトする。カード選択中は候補マスを薄く表示し、通常の合法手表示は重ねない。 |
| 援軍の意志 | 最大3個の生成を1個ずつ順番に見せる。各生成マスは紫ハイライトし、各生成後の反転も順番が分かるように見せる。カード選択中は候補マスを薄く表示し、通常の合法手表示は重ねない。 |
| 十字爆弾 / クロス爆弾 / 時限爆弾 | 爆弾本体の起爆と範囲爆破を同じ破壊系の流れで見せる。爆破対象マスは赤ハイライトする。 |
| 逃げる意志 | 移動先がなく爆発する場合、周囲1マス爆破と自身消滅を一括の爆発として見せる。 |
| ロボット掃除機 | 移動後に吸い込む。移動先で通常反転は起こさない。吸い込み対象は破壊とは違う吸い込みとして見せる。 |
| 悪食の意志 | 捕食で敵石に進入する場合、移動と捕食が同じ意味に見えるようにする。飢えによる消滅は通常破壊ではなく悪食の終了として見せる。 |
| 意志狩りの王 | 対象の敵石を狙い、そのマスへ移動しながら破壊する。破壊回避された場合は、元対象マスと回避先の意味が混ざらないように見せる。 |
| 究極多動神 | 直線移動を2回に分けて見せる。2マス以上の移動では途中の石を飛び越えることが分かるようにする。 |
| 盤面拡張 / 盤面拡張神 | 新しいマスが盤面に追加された直後に、追加範囲が分かるように見せる。 |
| 盤面縮小 / 盤面縮小神 | 選択中のマスや辺を紫ハイライトし、盤面縮小で1つ目以降を選んだ後の次候補マスと、盤面縮小神で角を選んだ後の2つ目候補マスには縮小方向の矢印も重ねる。盤面縮小神では矢印候補ごとの縮小予定辺マス列を既存の合法手表示と同じ青マスで見せる。確定後は穴画像を基調に、盤面縮小由来の黒いフレーム縁と内側エッジを重ね、配置・移動・反転経路に使えない穴マスであることが通常盤面でも分かるように表示する。 |
| 因果抹消 | 対象マスを石ごと破壊して穴にする。石破壊とマス消失が両方分かるようにする。 |
| 凍結の意志 | 凍結中は氷表示と残りターンを維持する。凍結された石は動けず、反転や破壊を受けないことが見た目で分かるようにする。 |
| 運命の意志 | 操作側には相手ターンを操作中であることを表示し、被操作側には入力不能で待機中であることを表示する。双方で効果中表示が欠けてはいけない。 |

## ネット対戦で特に守ること

ネット対戦の結果一致は共通ルール正本、入力再開はターン進行正本に従います。

演出面では、ライブ再生中の使用者側と相手側で、ハイライト、移動、反転、破壊、生成、通常石化の意味が食い違わないことを守ります。
