## 2. BENCHMARK-SAFE FIX DIRECTION

RECOMMENDED: Apply hard-filter at src/engine/selfplay-runner.js line 2062-2064

Current (buggy):
  const candidateMoves = (options && options.enableTacticalLookahead === false 
      && Array.isArray(forcedPlacement.moves) && forcedPlacement.moves.length > 0)
      ? forcedPlacement.moves
      : defaultCandidateMoves;  // ← ALLOWS lookahead escape when enabled

Fixed:
  const candidateMoves = (Array.isArray(forcedPlacement.moves) 
      && forcedPlacement.moves.length > 0
      && !(options && options.disableCornerEdgeHardFilter === true))
      ? forcedPlacement.moves   // ← HARD FILTER matches production
      : defaultCandidateMoves;

This ensures:
✓ Lookahead receives only forced moves (corners/edges) when they exist
✓ Aligns training (selfplay) with production behavior
✓ Prevents scorer from rewarding non-forced moves via tree value
✓ Maintains lookahead agency within forced set (choosing best corner vs best edge)
✓ Benchmark-safe: constrained candidate space won't regress if forced placement
  strategies are well-valued by movePlanContext/scoreMoveForCornerEdgePlan

## SUMMARY

Problem: Lookahead in SELFPLAY can override forced corner/edge intuition by exploring
         full move space and returning highest-tree-value move. PRODUCTION constrains
         lookahead to forced moves via hard filter (filterMovesByLv6PlacementPriority).

Root Cause: Line 2062 in src/engine/selfplay-runner.js allows candidateMoves=ALL when
            enableTacticalLookahead=true, instead of hard-filtering to forced moves.

Solution: Replace conditional filter with unconditional hard-filter that respects
          forced placement (line 2062), matching production's filterMovesByLv6PlacementPriority.

Validation: Add 4 regression tests (especially A & B) to test/selfplay.runner.test.js
            to ensure lookahead no longer escapes forced placement constraints.

Impact: Training alignment, reduced Lv6 CPU non-intuitive moves, potential small Elo
        adjustment. Tests will clarify if trade-off is balanced.
