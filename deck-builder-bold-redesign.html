前回から何を変えたか (批判的差分)

1. decoration
前回: 矩形に枠線だけ = HTML form 状態 / 今回: 角丸 brass border, 角金 ornament, 装飾罫線, マナオーブ, wax seal, gem orb を全部入れ直し。ゲーム画面の UI として成立するように装飾を主体で設計し直した
2. palette
前回: slate-blue (#589cff) + washed gold = admin panel / 今回: 深い紺 (`#0d141d`) + 真鍮 (`#d4a647`) + 8色 saturated type accent。タイプ色はマナオーブ・spine・gem・スウォッチで 4 段使い、スクロール前に「どのタイプ寄りか」が判別できる
3. typography
前回: 全部 Outfit 太さ変化のみ = hierarchy 偏平 / 今回: タイトル系 = DM Serif Display, 本文 = Outfit の二層。カード名は display serif で大きく (18px)、ラベル類は small caps + letter-spacing で格式感を持たせる
4. info density
前回: デッキ名 + 枚数 + 2ボタン / 今回: デッキ名 (display serif) + 形式 pill (e.g. STANDARD) + 枚数オーブ + タイプスウォッチバー (上に同色発光の細バーで比率可視化) + ボタン列。HS デッキ一覧と同等以上の情報量
5. active state
前回: 金縁 + IN USE 帯 だけ / 今回: brass border で囲み、右上に wax seal (回転 -8°, embossed text) で「現在使用中」が一目で分かる。ボディは warmer amber に、内側に brass highlight、box-shadow で全体 glow
6. empty slot
前回: dashed border + 小さい + (opacity 0.78) = 寂しい / 今回: dashed brass 1.5px + 中央に 60px brass halo + display serif の 42px "+" + "クリックして構築" 矢印付き。"ここタップしてね" がはっきり出る
