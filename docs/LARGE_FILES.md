# 大きなファイルの扱いと安全なプレビュー 🚨

このリポジトリで「巨大ファイルを読み込んで処理が止まる（応答しなくなる）」問題を防ぐための手順とツールをまとめます。

## すぐできる対処（推奨） ✅

- 大きいファイルを全文表示しない。代わりに「先頭／末尾」を確認する。
- 作業用の仮想環境や学習データディレクトリ（`.venv`, `data/`）をエディタ検索や索引から除外する。
- 大きいファイルはコミットしない（`.gitignore` に追加）。

## 付属ツール（このリポジトリに追加済み） 🔧

- `node scripts/list-large-files.js` — ワークスペース内の上位 N 個の大きいファイルを一覧表示（デフォルトで `.venv` と `data` を除外）。
- `node scripts/preview-file.js <path>` — 大きいファイルでも安全に「head + tail」を表示。バイナリ検出あり。全文は `--full` 指定でのみ表示。

例:

  - 一覧: `node scripts/list-large-files.js --limit 20`
  - プレビュー: `node scripts/preview-file.js data/runs/xxx.ndjson`

## エディタ（VS Code）での推奨設定

このリポジトリには `.vscode/settings.json` を追加しました。主な除外:

- `.venv/`, `data/`, `node_modules/` をファイルツリー・検索から除外

自分のエディタ設定に同様の除外を追加してください。

## もしファイルが不要なら

- 学習データや仮想環境はローカルに保管し、リポジトリに含めない（`.gitignore` に追加済み）。
- 大きい学習ログは圧縮するか外部ストレージへ移動（チーム合意が必要な場合は事前相談）。

## なぜこれで止まらなくなるのか（短く）

- 大きいファイルを丸ごと読み込むと I/O とメモリが増え、ツールやエディタがブロックされるためです。先頭/末尾だけを扱えば即座に確認でき、安全です。
