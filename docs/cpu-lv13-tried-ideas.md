# レベル13 試した案と効果の一覧

- 役割: Lv13を強くするために試した案を、効果の大きさで並べ直した早見表。次に改良を試すとき、同じ案を繰り返さないために使う。
- 状態: 2026-10-14時点。採用版は `lv13-late-cards`（`game/ai/cpu-lv13-search.ts` の `LV13_SEARCH_CONFIG`）に、1手番の手順の再利用（`game/cpu-lv10-turn.ts`）を加えたもの。
- 正本: 各実験の条件と数字の詳細は [開発・評価記録](cpu-lv13-development-plan.md)（以下「記録」）、外部調査の提案は [人間相手に強くするための調査・提案](cpu-lv13-human-strength-research.md)（以下「調査」）。ゲーム仕様は [01-rulebook.md](../01-rulebook.md) §14.11。
- 対象外: 新しい実験の計画と仕様の変更。数字は記録からの転記で、この資料のために測り直してはいない。

## 先に結論

1. **読む量を増やしても強くならない。** 次の案はいずれも、対局では誤差の範囲（50〜56%）だった。
   - 予算を2倍にする。
   - 遷移上限を6,144に上げる。
   - 判断を変えずに27%高速化する。
   - 余った時間で読みの幅を広げる。
   - 僅差の判断だけ、余った予算で追加の仮想世界でも読み直す。
2. **評価の重みや項目を変えても強くならない。** 次の変更は、すべて45〜53%だった。
   - 角・辺・安定石・生存の重み。
   - 辺の形。
   - 終局結果への当てはめ直し。
3. **はっきり効いたのは、カードを使う時の「ためらい」だけ。** カード使用の余裕幅0.1は対Lv12で67%。手札破壊の余裕幅0.08は約55%。
4. **はっきり逆効果だったのは、カードを使わない手を無理に残す案、またはカードを使わせない案。** 31〜47%だった。
5. **CPU同士の自己対局では、小さな改良は測れない。**
   - 序盤の山札の巡りで勝敗が決まる局が多い。十分に試したseedの約3割は、どちらが打っても同じ色が勝つ。また16〜30%の対局は、序盤に片方の石が全滅して終わる。
   - 32局の誤差は±9%、128局でも±4%ある。
6. **人間の対局条件では、布石の差が勝敗の大半を決める。**
   - 布石の条件は、CPUが初期99・獲得2倍、人間が0・1倍。
   - 人間役との対局は30勝2敗だった。
   - そのため、自己対局での改良は、対人戦の勝率としては測れない。
7. **CPU同士の対局で白が負けた局の中盤〜終盤に、直せる判断の誤りは見つからなかった。**
   - 白の評価が大きく下がった区間の82%で、黒が高価なカードを使っていた。
   - 深い読みが勧めた手は、実際に終局まで打ち切ると本番の手より平均3.4石悪かった（43局面）。
   - 人間は布石が少なく、中盤に高価なカードを使える場面は少ない（第12段階）。
8. **人間の対局条件では、終盤にカードを残したまま負ける癖があり、これは直せた。**
   - 残り12配置以下ではカード使用の余裕幅を0にし、読みの中でどの手も終局する時は終局の石差で選ぶ。
   - 36手目からの打ち直しで石差+2.8（標準誤差0.9）。勝率の差は誤差の範囲。CPU同士は63勝64敗1分で退行なし（第13段階）。
   - 手札・布石の評価を終盤ほど薄める案は、効果が誤差の範囲だった。

## 実験の失敗（結果が無効だったもの）

- 予算2倍〜4倍の初回（A、B3）
  - 4,096遷移を超えた探索結果が受け渡し検査で無効になり、最初の合法手で代用されていた。
  - 遷移の上限は、その後 `LV10_ADVISOR_MAX_TRANSITIONS = 8192` に一般化した。
- 2026-10-07の設定比較（W1、W2、C1、G3、D1）
  - Lv13をLv12から作り直した際に、実験用の設定上書き（`tuning`・`valueWeights`）が消えていた。そのため、同じ設定同士の対戦になっていた。
  - 上書きを復元してから測り直した。
- 時計ありの対局は、PCの負荷で結果が揺れる。比較は時計なしで、遷移数で止める条件を基本にした。
- T1bは、PCのメモリ不足で途中で止めた。

## 測り方について分かったこと

| 物差し | 精度 | 使える場面 | 限界 |
| --- | --- | --- | --- |
| 32局の対局（先後交換） | 誤差±9% | 大きな改善・悪化の確認 | 5%程度の差は見えない |
| 512遷移の高速対局128局 | 誤差±4% | 退行の確認 | 本番（6,144遷移）とは読みの深さが違う |
| 後悔値（深い読みの正解との差） | 32局の勝敗より桁違いに高い | 読みの量・幅の比較 | 正解側も同じ評価を使うので、評価の変更は判定できない。後悔値が約5%改善しても、対局では検出できなかった |
| 終局結果との照合（ロジスティック回帰） | 対局ごとの交差検証 | 評価の項目・係数の比較 | 予測が良くなっても、探索の強さに結びつかなかった（O1） |
| 人間役との対局 | — | 人間の対局条件での確認 | 布石の差で30勝2敗になり、改良の差が出ない |
| 終盤局面の対比較（同じ局面・同じ乱数から、片側の打ち方だけ変えて終局まで打つ） | 45局面で石差の標準誤差約2石 | 終盤だけ変える案の比較 | 1局面に約2分かかる（4並列で90局面に約50分） |
| 1手だけ固定した打ち切り（同じ局面・同じ乱数から、最初の1手だけ変えて終局まで打つ） | 43局面で石差の標準誤差約2.6石 | 深い読みの後悔が本物かの確認 | 1局面に約10分かかる（4並列で43局面に約2時間） |
| 人間役との対局の36手目からの打ち直し（乱数の種を変えた複数通りを、基準と候補の両方で打って対にする） | 78局面×3通りで石差の標準誤差約0.8〜1.1石 | 終盤の打ち方の比較 | 判断が1つ変わると約8割の局で展開が変わる。1通りでは標準誤差1.3〜2石。78局面×2通りに4並列で約80分 |

- 深い読みの後悔値が大きい局面でも、深い読みの手が実際に良いとは限らない。後悔0.1以上の43局面を打ち切ると、深い読みの手のほうが平均3.4石悪かった（第12段階）。
- 序盤は山札の巡りの影響が大きい。序盤の全滅も、同じseedでは同じ色に起きやすい。
- 読みが浅いほど、カードを使いすぎる。2,048遷移でカードを使った局面の16%は、16,384遷移では使わない手に変わる（逆向きの変化は4%）。カード使用の余裕幅が効いたのは、このためと考えられる。
- 開発比較では、終わった最初の5局で3敗した候補は打ち切った（ユーザー指定）。
