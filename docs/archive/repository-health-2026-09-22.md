# リポジトリ健全性の修復記録（2026-09-22）

役割: 今回の調査・修正・検証の記録。対象は現在のカードリバーシとビルド・検査処理。仕様の正本は [ルールブック](../../01-rulebook.md)、責務境界は [内部契約](../architecture-contracts.md)。新しいゲーム仕様、CPUの強さ変更、本番公開、長時間の学習は対象にしない。

## 現行仕様との整合

失敗したテストを一律に製品不具合と扱わず、以下の履歴と現行コードを照合した。古い仕様へ戻す製品変更はしていない。

- `0272e80df`: ガチャの手の見た目専用化。旧所持音の保存を残したまま、現在の配置音選択は既定音へ戻ることを検査する。
- `5b998f377`: 観測ガチャの演出刷新。遅延ロードする `styles-feature-gacha.css` に対して現行の装飾とサイズを検査する。
- `85b0f0942`: 通信の非公開情報保護。公開room情報からデッキコードを除外する期待値へ更新し、再帰的な漏洩検査にもコードを追加する。
- `5f986cd6a`: 破壊演出は全アニメーション完了または期限で終了する。ドラゴン・隕石も部分完了だけでは終了しないことと、終了通知が来ない場合の期限を両方検査する。
- `d29c55fd8`: カードカタログの静的依存、Lv10 CPUの公開APIと比較CLIを反映。カタログ欠損時の失敗と空カタログ拒否をそれぞれ検査する。
- 通信ターン制限の公開API追加を列挙テストへ反映する。境界値の挙動は既存の `shared.network-contract` / `utils.match-authority.contract-types` テストで検査する。
- ランタイム依存・可変状態の固定値は、元の `976fc9cf9` のファイルをGitから読み取った検査結果と比較して更新した。CPU助言の依存追加、静的カタログ、WebSocket移行、廃止済みレーティング依存の除去を確認。可変状態は86から87となり、追加の `advisedTurnInFlight` は既存の多重実行テストで解放を確認する。

## 検証結果

- 全1,094テストファイル（8,264ケース）を実行。失敗した20ファイルは原因を切り分け、修正後に146ケースすべて合格した。回帰テストの追加を含むため、最初の全体実行と再実行の件数は同一ではない。
- `npm run checkall`、`npm run typecheck`（通常・training）、Worker mirror検査が合格。
- フォント12組の検査と、classic/Vite × Pixi/DOM compatibilityの4経路の実ブラウザ試験が合格。
- 通常URL `http://127.0.0.1:8000/` のVite配信でPixi・DOM compatibilityを確認。デッキ画面を閉じる操作とEscape後にフォーカスが戻り、並行世界3リンクに別タブの説明が関連付く。通常の着手・CPU応答・演出完了後の盤面を確認し、ページエラーは0件。
- `worker-public/` のみを配信する一時サーバーで、classic・Vite・Web Workerを利用できない場合の3経路のONNX推論に成功。出力100要素と選択結果が一致した。一時サーバーは検査後に終了。
- 依存更新後はlockfileだけでなく、実際のインストール済みファイルの版を確認。`npm audit` の指摘は0件。更新後のViteビルド、画像関連等の5ファイル20ケース、背景13枚・UI画像3枚の変換検査も合格した。
- 別作業を除いたGit indexの内容を検証用コピーに出し、ブラウザ・Workerの配布生成物を生成した。同じ20テストファイル・146ケースがこのコピーでも合格し、コミットするフォントの収録元一覧にも未追跡のCPUコードを含めていない。
- 実行ログ、Jest JSON結果、ブラウザ結果・画像、依存グラフの比較記録はローカルの `.git/repo-health-*` に保存。これらはコミット対象外。

最終ソースと更新済み依存に対する `npm run checkall` は合格し、内部の `build:vite` とWorker mirror検査も成功した。通常サーバーは更新済み依存を読み込んで再起動し、独立したプロセスとして継続稼働。最後に8000のHTTP 200、配信元がこのリポジトリであること、起動コマンド・親子プロセスを確認した。

実装後、2名のサブエージェントが独立にステージ済み差分をレビューした。1名はコードとテストの仕様整合、もう1名は依存・配布ファイル・フォント・生成HTMLを担当し、重大・中程度の具体的な不具合はどちらも指摘なし。配布側レビューでは、ONNX 5ファイルのハッシュ、フォント12組、Vite manifest 45項目の参照、3リンクの説明関連付けが生成HTML全6入口へ反映されていることも照合した。

## 既存変更の扱い

開始時の作業ツリーには、素材の削除・改名、CPU開発、性能計測、生成物などの別作業があった。ユーザーから素材の削除・改名は意図した整理との回答を得たため、内容が変わっていないことを照合した103件の移動と、16件の制作ファイルの削除を記録する。追跡済みの素材から不足していたWorker mirror 108件も生成し、最後の素材名検査は1,240ファイルすべて合格した。

CPU開発・性能計測・追加の制作資料・ルートの `AGENTS.md` などはそのまま残し、今回のコミットへ混ぜない。配布生成物は今回の変更だけを取り出した検証用コピーでも生成し、通常配信には既存の作業内容を含む現在のソースからビルドしたものを使う。

未追跡のLv13比較スクリプトを現在の作業ツリーで検査できるよう追加した `selfplay:compare:lv13` の入口は、対象スクリプトと同じ未コミットのCPU作業側へ残している。コミットした保守コマンド6件は、すべて追跡済みの実装を呼び出す。

本記録は、実行した検査と再現できた問題の解消を示す。未発見の不具合が存在しないという保証、素材の商用利用権の確定、Steamでの公開手続きや本番公開の完了を示すものではない。
