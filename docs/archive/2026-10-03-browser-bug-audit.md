# 2026-10-03 ブラウザ不具合検証記録

この資料は今回の検証と修正の記録です。対象はカードリバーシのブラウザ操作・対局進行・カード・通信です。ルールの正本は [公式ルールブック](../../01-rulebook.md)、責務境界の正本は [設計契約](../architecture-contracts.md) です。新しい製品仕様の決定、長時間のCPU訓練、本番への公開は対象外です。

## 確認した不具合と修正

- 通常盤の「盤面サイズ」で数字を1桁ずつ入力すると、途中の空欄や `1` が即座に補正される。ローカル設定では `10` が `16` となり、部屋作成設定では空欄が `4` となることを、修正前のChromium統合テストで確認した。
- ローカル設定と部屋作成設定の入力処理を修正した。入力中の未完成・範囲外の値は編集中の文字として保ち、有効な値になった時点で設定へ反映する。入力確定時の正規化、円形の偶数・正方形制約、ホイール操作、対戦中の部屋固定は維持する。
- 対象選択の既存テスト5件は、pipelineが残さなかった対象選択をUIが再生成する旧挙動を要求していた。現在の契約に合わせて、pipelineが残した対象選択への識別子付与を確認する形へ修正し、通常・デバッグ双方で無効化後に対象選択が復活せず、消費と使用済み状態が維持される4ケースを追加した。
- カード依存関係の固定検査は、既存のゾンビ初期化処理への静的import追加を取り込めていなかった。対象のimportと変更された行位置を確認し、件数・固定ハッシュを更新した。依存境界の検査と違反を検出する負例は維持し、当該importの検査を追加した。
- 状態所有者の固定検査は、既存の対象選択再生成廃止で変更された行位置を取り込めていなかった。旧版の固定ハッシュを再現してから現行版と比較し、87個の所有者・変更種別・リセット方針に変化がないことを確認して固定ハッシュを更新した。
- 移植比較データは既存の転生候補修正に未追従だった。既存の収録スクリプトで `godot-conformance-2026-10-03` を作成し、211ケース・706ステップを確認した。入力は旧基準と全件一致し、出力差分は理論の化身・カオス召喚・転生の意志の3ケース、決定性ベクトル差分は転生候補だけだった。旧基準は書き換えず、保存形式の互換テストでも引き続き使用する。
- カオス召喚の固定seed検査も、同じ候補更新による召喚先変更に未追従だった。再生で `REGEN`・復活回数3を確認し、盤面・イベント種別・乱数状態が変わらないことを検査してmarkerと全結果のハッシュを更新した。現行保存・再生fixtureは既存の `godot-data-contract fixtures --write-current` で更新し、歴史fixtureは保持した。
- 旧保存の移行検査は、延命の意志のコスト4の旧内容hashをコスト6の現行版へ移せると期待していた。旧ルールを隔離して内容hashの一致を検査した上で旧版同士の移行・表示descriptorの厳密な検査を維持し、現行版での明示拒否を追加した。現在の内容hashと文書を整合させた。
- 配信比較ツールのカードAPI件数・ハッシュを、既存の291項目の固定検査に合わせた。通信の固定seed結果も現在の公開状態で収録し、直接実行とHTTP経由の全結果の一致を維持した上で、非公開の山札・乱数・相手の未公開手札が含まれず、山札の残り枚数が正しいことを明示的に追加検査した。

## 通常配信の最終確認

`http://127.0.0.1:8000/` は修正版のVite入口をHTTP 200で配信している。PID 8084はこのrepoの `serve-with-fallback.js --http-server-child`、親PID 18412は `scripts/serve-with-fallback.js` で、2026-10-03 01:11の作業開始前から稼働している継続プロセスを再利用した。今回の一時的なツールセッションで起動したサーバーではない。サーバーは停止せず、ビルド後と最終確認時の両方で生存・HTTP 200を確認した。

画面操作成功の証拠は独立した統合テストであり、8000のHTTP 200だけで画面操作成功と扱っていない。開始時から存在したモデルmanifestの変更1件と未追跡のキャラクター素材フォルダー1件は今回の変更に含めない。

## 確認できない範囲

- アプリ内ブラウザで8000を開く操作は、保存済みブラウザ権限の検証が利用できないという内部エラーで2回失敗した。そのアクセスを別経路で迂回せず、コード検証としての独立した統合テストを実行した。
- 実Android/iOS端末でのタッチ操作、外部の本番対戦サービス、あらゆるカードの組合せを網羅した保証は含まない。
