# UI Game Boundary Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove UI/network and renderer knowledge of game internals while preserving current network authority, pending selection, legal hint, and visual preview behavior.

**Architecture:** Keep canonical gameplay and pending selection semantics in `game/` and keep rendering in `ui/`. Add narrow explicit boundary adapters so UI/network calls injected contract functions instead of reaching into `game/logic/cards-internal/*` or resolving game modules inside action serializers. For board hints, extract a pure projection helper so `board-renderer` and `diff-renderer` consume the same precomputed sets instead of duplicating card-specific decision logic.

**Tech Stack:** TypeScript/CommonJS, Jest with ts-jest/babel-jest, classic browser globals, Cloudflare Worker mirror generated by `npm run worker:prepare`.

---

## Preconditions

- Do not start implementation in a checkout with unrelated dirty changes unless the user explicitly approves that isolation. At the time this plan was written, the checkout had many unrelated modified and untracked files.
- Before each task, run `git status --short` and classify dirty files.
- Do not edit `worker-public/` first. If source changes affect browser-served assets, run `npm run worker:prepare` only in the final mirror task.
- Preserve `01-rulebook.md` unless a player-visible behavior intentionally changes. This refactor is behavior-preserving, so no rulebook change is expected.
- Preserve `docs/architecture-contracts.md` behavior. Only update it if the refactor stabilizes a new boundary name or public module ownership.

## Behavior To Preserve

- Network mode must not locally mutate canonical gameplay state for `place`, `pass`, `use_card`, `cancel_card`, or `destroy_hand_card` before the server-authoritative publish response.
- Deferred pending selection publishes must keep `pendingSelectionState.pendingEffectId` when present.
- Command publish payloads must not send client-authored snapshots or playback events for authority commands.
- `use_card` with unknown card type must still fail closed when the public card resolver is expected to exist.
- `PendingCoordinator` absence in tests must still allow network `use_card` authority publish fallback.
- Legal hints, `legal-free`, `selectable-friendly`, random spawn preview, TABOO_REVERSE highlight, FATE_WILL controlled-turn hints, BOARD_SHRINK direction hints, and SUPER_ATTRACTION hover preview must remain visually identical.
- `game/` and `shared/` must remain headless. Do not add DOM, `window`, audio, timer, or network client dependencies there.

## File Structure

### New Files

- `test/ui.network-boundary-imports.test.ts`
  - Static guard for forbidden UI/network imports from `game/logic/cards-internal/*`.
  - Later expanded to reject game-module fallback resolution inside `ui/network/action-bridge.ts` and `ui/network/command-payload.ts`.

- `ui/network/game-contract-adapter.ts`
  - Explicit UI boundary adapter over public game surfaces only.
  - Reads `game/logic/cards` and `game/turn/pending-coordinator` as public game APIs.
  - Exposes small functions: `resolveCardTypeForId`, `getPendingEffectType`, `getPendingSelectionContract`, `shouldDeferNetworkPublishForPendingType`, `syncPendingSelectionActionCache`, `applyPendingSelectionCardContext`.

- `test/ui.network-game-contract-adapter.test.ts`
  - Characterizes adapter fallbacks and injected overrides without loading `cards-internal` from UI/network.

  - Pure projection helper. No DOM, no globals, no side effects.
  - Accepts `cardLogic`, `getLegalMoves`, player helpers, board shape, and viewer flags as dependencies.

```ts
'use strict';

declare const __non_webpack_require__: NodeRequire | undefined;

const _require: NodeRequire = (typeof __non_webpack_require__ !== 'undefined')
  ? __non_webpack_require__
  : require;

type ModuleResolver = (requirePath: string, globalKey: string) => any;

interface NetworkGameContractAdapterOptions {
  root?: any;
  cardLogicModule?: any;
  pendingCoordinatorModule?: any;
  moduleResolver?: ModuleResolver;
}

function resolveRuntimeRoot(root?: any): any {
  if (root && typeof root === 'object') return root;
  try {
    if (typeof globalThis !== 'undefined') return globalThis as any;
  } catch (e) { /* ignore */ }
  return {};
}

function resolveModule(defaultRoot: any, resolver: ModuleResolver | undefined, requirePath: string, globalKey: string): any {
  if (typeof resolver === 'function') {
    const resolved = resolver(requirePath, globalKey);
    if (resolved) return resolved;
  }
  try {
    if (typeof _require === 'function') {
      const mod = _require(requirePath);
      if (mod) return mod;
    }
  } catch (e) { /* ignore */ }
  try {
    if (defaultRoot && defaultRoot[globalKey]) return defaultRoot[globalKey];
  } catch (e) { /* ignore */ }
  return null;
}

function createNetworkGameContractAdapter(options?: NetworkGameContractAdapterOptions): any {
  const opts = (options && typeof options === 'object') ? options : {};
  const root = resolveRuntimeRoot(opts.root);
  let cardLogicModule = Object.prototype.hasOwnProperty.call(opts, 'cardLogicModule')
    ? opts.cardLogicModule
    : undefined;
  let pendingCoordinatorModule = Object.prototype.hasOwnProperty.call(opts, 'pendingCoordinatorModule')
    ? opts.pendingCoordinatorModule
    : undefined;

  function getCardLogicModule(): any {
    if (typeof cardLogicModule !== 'undefined') return cardLogicModule || null;
    cardLogicModule = resolveModule(root, opts.moduleResolver, '../../game/logic/cards', 'CardLogic');
    return cardLogicModule || null;
  }

  function getPendingCoordinatorModule(): any {
    if (typeof pendingCoordinatorModule !== 'undefined') return pendingCoordinatorModule || null;
    pendingCoordinatorModule = resolveModule(root, opts.moduleResolver, '../../game/turn/pending-coordinator', 'PendingCoordinator');
    return pendingCoordinatorModule || null;
  }

  function resolveCardTypeForId(cardId: any): string | null {
    if (!cardId) return null;
    const cardLogic = getCardLogicModule();
    if (!cardLogic || typeof cardLogic.getCardDef !== 'function') return null;
    const def = cardLogic.getCardDef(cardId);
    return def && def.type ? String(def.type) : null;
  }

  function getPendingSelectionContract(cardType: any): any {
    if (!cardType) return null;
    const pendingCoordinator = getPendingCoordinatorModule();
    if (!pendingCoordinator || typeof pendingCoordinator.getPendingSelectionContract !== 'function') return null;
    try {
      return pendingCoordinator.getPendingSelectionContract(cardType) || null;
    } catch (e) {
      return null;
    }
  }

  function shouldDeferNetworkPublishForPendingType(cardType: any): boolean {
    if (!cardType) return false;
    const pendingCoordinator = getPendingCoordinatorModule();
    if (pendingCoordinator && typeof pendingCoordinator.shouldDeferNetworkPublishForPendingType === 'function') {
      try {
        return pendingCoordinator.shouldDeferNetworkPublishForPendingType(cardType) === true;
      } catch (e) {
        return false;
      }
    }
    const contract = getPendingSelectionContract(cardType);
    return !!(contract && contract.deferNetworkPublish === true);
  }

  function getPendingEffectType(cardStateValue: any, playerKey: any, normalizePlayerKey?: any): any {
    const pendingCoordinator = getPendingCoordinatorModule();
    if (!pendingCoordinator || typeof pendingCoordinator.getPendingEffectType !== 'function') return null;
    try {
      const resolvedPlayerKey = typeof normalizePlayerKey === 'function'
        ? normalizePlayerKey(playerKey)
        : playerKey;
      return pendingCoordinator.getPendingEffectType(cardStateValue, resolvedPlayerKey);
    } catch (e) {
      return null;
    }
  }

  function syncPendingSelectionActionCache(pendingState: any, syncOptions?: any): any {
    const pendingCoordinator = getPendingCoordinatorModule();
    if (pendingCoordinator && typeof pendingCoordinator.syncPendingSelectionActionCache === 'function') {
      try {
        return pendingCoordinator.syncPendingSelectionActionCache(pendingState, syncOptions);
      } catch (e) { /* ignore */ }
    }
    return { cleared: [], retained: [] };
  }

  function applyPendingSelectionCardContext(params: any, actor: any, pendingSelectionState?: any, extraOptions?: any): any {
    const pendingCoordinator = getPendingCoordinatorModule();
    if (pendingCoordinator && typeof pendingCoordinator.applyPendingSelectionCardContext === 'function') {
      try {
        return pendingCoordinator.applyPendingSelectionCardContext(params, actor, pendingSelectionState, extraOptions);
      } catch (e) { /* ignore */ }
    }
    return params;
  }

  return {
    resolveCardTypeForId,
    getPendingSelectionContract,
    shouldDeferNetworkPublishForPendingType,
    getPendingEffectType,
    syncPendingSelectionActionCache,
    applyPendingSelectionCardContext
  };
}

export = {
  createNetworkGameContractAdapter
};
```

```ts
interface BoardShape {
  rows: number;
  cols: number;
}

interface BoardHintProjectionInput {
  gameState: any;
  cardState: any;
  playerKey: string;
  boardShape: BoardShape;
  canControlCurrentTurn: boolean;
  isHumanTurn: boolean;
  cardLogic?: any;
  getLegalMoves?: (gameState: any, protectedStones: any, permaProtectedStones: any) => any[];
  expansions?: any[];
}

function normalizePointKey(target: any): string | null {
  const row = Number(target && target.row);
  const col = Number(target && target.col);
  return Number.isInteger(row) && Number.isInteger(col) ? `${row},${col}` : null;
}

function collectPendingSelectedTargetHighlightKeys(pending: any): Set<string> {
  const out = new Set<string>();
  if (!pending || pending.stage !== 'selectTarget') return out;
  const pendingType = String(pending.type || '').toUpperCase();
  const add = (target: any) => {
    const key = normalizePointKey(target);
    if (key) out.add(key);
  };
  if (
    pendingType === 'POSITION_SWAP_WILL' ||
    pendingType === 'SUPER_ATTRACTION_WILL' ||
    pendingType === 'BOARD_EXPANSION_GOD' ||
    pendingType === 'BOARD_SHRINK_GOD'
  ) {
    add(pending.firstTarget);
  }
  if (pendingType === 'BOARD_EXPANSION_GOD' || pendingType === 'BOARD_SHRINK_WILL') {
    const selectedTargets = Array.isArray(pending.selectedTargets) ? pending.selectedTargets : [];
    selectedTargets.forEach(add);
  }
  return out;
}

function resolveSelectedCardType(cardLogic: any, cardId: any): string {
  if (!cardLogic || !cardId) return '';
  try {
    if (typeof cardLogic.getCardType === 'function') {
      const type = cardLogic.getCardType(cardId);
      if (type) return String(type);
    }
  } catch (e) { /* ignore */ }
  try {
    const def = typeof cardLogic.getCardDef === 'function' ? cardLogic.getCardDef(cardId) : null;
    return def && def.type ? String(def.type) : '';
  } catch (e) {
    return '';
  }
}

function collectRandomSpawnPreviewHighlightKeys(input: BoardHintProjectionInput, pending: any): Set<string> {
  const out = new Set<string>();
  if (!input || input.canControlCurrentTurn !== true) return out;
  if (pending) return out;
  const cardState = input.cardState;
  const selectedOwnerKey = cardState && (cardState.selectedCardOwnerKey === 'white' || cardState.selectedCardOwnerKey === 'black')
    ? cardState.selectedCardOwnerKey
    : input.playerKey;
  if (selectedOwnerKey !== input.playerKey) return out;
  const selectedCardId = cardState && cardState.selectedCardId;
  if (!selectedCardId) return out;
  const cardLogic = input.cardLogic;
  const selectedCardType = resolveSelectedCardType(cardLogic, selectedCardId);
  let targets: any[] = [];
  try {
    if (selectedCardType === 'REINFORCEMENT_WILL' && cardLogic && typeof cardLogic.getReinforcementWillTargets === 'function') {
      targets = cardLogic.getReinforcementWillTargets(input.cardState, input.gameState, input.playerKey) || [];
    } else if (selectedCardType === 'SUPPORT_TROOPS_WILL' && cardLogic && typeof cardLogic.getSupportTroopsWillTargets === 'function') {
      targets = cardLogic.getSupportTroopsWillTargets(input.cardState, input.gameState, input.playerKey) || [];
    }
  } catch (e) {
    targets = [];
  }
  targets.forEach((target) => {
    const key = normalizePointKey(target);
    if (key) out.add(key);
  });
  return out;
}

function resolveDirectionName(direction: any): string | null {
  const row = Number(direction && direction.row);
  const col = Number(direction && direction.col);
  if (Math.abs(col) >= Math.abs(row) && col !== 0) return col > 0 ? 'right' : 'left';
  if (row !== 0) return row > 0 ? 'down' : 'up';
  return null;
}

function buildBoardShrinkGodDirectionHintMap(pending: any, selectableTargets: any[]): Map<string, string> {
  const out = new Map<string, string>();
  if (!pending || pending.stage !== 'selectTarget' || String(pending.type || '').toUpperCase() !== 'BOARD_SHRINK_GOD') return out;
  const firstRow = Number(pending.firstTarget && pending.firstTarget.row);
  const firstCol = Number(pending.firstTarget && pending.firstTarget.col);
  if (!Number.isInteger(firstRow) || !Number.isInteger(firstCol) || !Array.isArray(selectableTargets)) return out;
  selectableTargets.forEach((target) => {
    const row = Number(target && target.row);
    const col = Number(target && target.col);
    if (!Number.isInteger(row) || !Number.isInteger(col)) return;
    const direction = resolveDirectionName({ row: row - firstRow, col: col - firstCol });
    if (direction) out.set(`${row},${col}`, direction);
  });
  return out;
}

function buildBoardShrinkWillDirectionHintMap(pending: any, selectableTargets: any[]): Map<string, string> {
  const out = new Map<string, string>();
  if (!pending || pending.stage !== 'selectTarget' || String(pending.type || '').toUpperCase() !== 'BOARD_SHRINK_WILL') return out;
  const selectedTargets = Array.isArray(pending.selectedTargets) ? pending.selectedTargets : [];
  if (selectedTargets.length <= 0 || !Array.isArray(selectableTargets)) return out;
  selectableTargets.forEach((target) => {
    const row = Number(target && target.row);
    const col = Number(target && target.col);
    if (!Number.isInteger(row) || !Number.isInteger(col)) return;
    const explicitDirection = resolveDirectionName(target && target.direction);
    if (explicitDirection) {
      out.set(`${row},${col}`, explicitDirection);
      return;
    }
    for (let index = selectedTargets.length - 1; index >= 0; index -= 1) {
      const selected = selectedTargets[index];
      const selectedRow = Number(selected && selected.row);
      const selectedCol = Number(selected && selected.col);
      if (!Number.isInteger(selectedRow) || !Number.isInteger(selectedCol)) continue;
      const rowDelta = row - selectedRow;
      const colDelta = col - selectedCol;
      if (Math.abs(rowDelta) + Math.abs(colDelta) !== 1) continue;
      const direction = resolveDirectionName({ row: rowDelta, col: colDelta });
      if (direction) out.set(`${row},${col}`, direction);
      break;
    }
  });
  return out;
}

function collectBoardShrinkGodPreviewHighlightKeys(pending: any, selectableTargets: any[]): Set<string> {
  const out = new Set<string>();
  if (!pending || pending.stage !== 'selectTarget' || String(pending.type || '').toUpperCase() !== 'BOARD_SHRINK_GOD') return out;
  const firstRow = Number(pending.firstTarget && pending.firstTarget.row);
  const firstCol = Number(pending.firstTarget && pending.firstTarget.col);
  if (!Number.isInteger(firstRow) || !Number.isInteger(firstCol) || !Array.isArray(selectableTargets)) return out;
  selectableTargets.forEach((target) => {
    const lineCells = Array.isArray(target && target.lineCells) ? target.lineCells : [target];
    lineCells.forEach((cell) => {
      const row = Number(cell && cell.row);
      const col = Number(cell && cell.col);
      if (!Number.isInteger(row) || !Number.isInteger(col)) return;
      if (row === firstRow && col === firstCol) return;
      out.add(`${row},${col}`);
    });
  });
  return out;
}

function buildTabooLegalSet(input: BoardHintProjectionInput, pending: any, showLegalHints: boolean): Set<string> {
  const out = new Set<string>();
  const cardLogic = input.cardLogic;
  if (!showLegalHints || !pending || pending.type !== 'TABOO_REVERSE_WILL') return out;
  if (!cardLogic || typeof cardLogic.getTabooReverseCandidates !== 'function') return out;
  const rows = input.boardShape && Number.isInteger(input.boardShape.rows) ? input.boardShape.rows : 8;
  const cols = input.boardShape && Number.isInteger(input.boardShape.cols) ? input.boardShape.cols : 8;
  const visit = (row: number, col: number) => {
    const candidates = cardLogic.getTabooReverseCandidates(input.cardState, input.gameState, input.playerKey, row, col);
    if (Array.isArray(candidates) && candidates.length > 0) out.add(`${row},${col}`);
  };
  for (let row = 0; row < rows; row += 1) {
    for (let col = 0; col < cols; col += 1) {
      if (input.gameState && input.gameState.board && input.gameState.board[row] && input.gameState.board[row][col] === 0) {
        visit(row, col);
      }
    }
  }
  const expansions = Array.isArray(input.expansions) ? input.expansions : [];
  expansions.forEach((expansion) => {
    if (expansion && Number(expansion.owner) === 0) visit(Number(expansion.row), Number(expansion.col));
  });
  return out;
}

function buildBoardHintProjection(input: BoardHintProjectionInput): any {
  const cardState = input.cardState || {};
  const pendingByPlayer = cardState.pendingEffectByPlayer || {};
  const pending = pendingByPlayer[input.playerKey] || null;
  const cardLogic = input.cardLogic || {};
  const selectableTargets = cardLogic && typeof cardLogic.getSelectableTargets === 'function'
    ? (cardLogic.getSelectableTargets(input.cardState, input.gameState, input.playerKey) || [])
    : [];
  const selectableTargetSet = new Set<string>();
  selectableTargets.forEach((target: any) => {
    const key = normalizePointKey(target);
    if (key) selectableTargetSet.add(key);
  });
  const isSelectingTarget = !!(pending && pending.stage === 'selectTarget' && selectableTargets.length > 0);
  const randomSpawnPreviewSet = input.isHumanTurn
    ? collectRandomSpawnPreviewHighlightKeys(input, pending)
    : new Set<string>();
  const showLegalHints = input.isHumanTurn === true
    && !isSelectingTarget
    && randomSpawnPreviewSet.size <= 0
    && input.canControlCurrentTurn === true;
  let normalLegalSet = new Set<string>();
  if (showLegalHints && typeof input.getLegalMoves === 'function') {
    let context = { protectedStones: [], permaProtectedStones: [] };
    if (cardLogic && typeof cardLogic.getCardContext === 'function') {
      try {
        context = cardLogic.getCardContext(input.cardState) || context;
      } catch (e) { /* ignore */ }
    }
    const legalMoves = input.getLegalMoves(input.gameState, (context as any).protectedStones, (context as any).permaProtectedStones) || [];
    normalLegalSet = new Set(legalMoves.map((move: any) => `${move.row},${move.col}`));
  }
  const tabooLegalSet = buildTabooLegalSet(input, pending, showLegalHints);
  const legalSet = new Set<string>([...normalLegalSet, ...tabooLegalSet]);
  return {
    pending,
    selectableTargets,
    selectableTargetSet,
    isSelectingTarget,
    showLegalHints,
    normalLegalSet,
    tabooLegalSet,
    legalSet,
    randomSpawnPreviewSet,
    selectedTargetHighlightSet: input.isHumanTurn ? collectPendingSelectedTargetHighlightKeys(pending) : new Set<string>(),
    boardShrinkGodPreviewHighlightSet: input.isHumanTurn ? collectBoardShrinkGodPreviewHighlightKeys(pending, selectableTargets) : new Set<string>(),
    boardShrinkGodDirectionHintMap: buildBoardShrinkGodDirectionHintMap(pending, selectableTargets),
    boardShrinkWillDirectionHintMap: buildBoardShrinkWillDirectionHintMap(pending, selectableTargets)
  };
}

export = {
  buildBoardHintProjection,
  collectPendingSelectedTargetHighlightKeys,
  collectRandomSpawnPreviewHighlightKeys,
  buildBoardShrinkGodDirectionHintMap,
  buildBoardShrinkWillDirectionHintMap,
  collectBoardShrinkGodPreviewHighlightKeys
};
```
