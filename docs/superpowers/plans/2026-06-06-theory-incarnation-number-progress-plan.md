> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `理論の化身` (`theory_incarnation_01`, `THEORY_INCARNATION`) count multiplier-adjusted number-cell charge toward its 42-point use condition.

**Architecture:** Keep authority in headless turn resolution. `game/turn/action-phase/place-resolution.ts` already computes both printed number-cell value and multiplier-adjusted gained value; the progress ledger should receive the adjusted value while normal flip charge remains outside the theory condition. Update player-facing source-of-truth docs and focused tests before implementation.
