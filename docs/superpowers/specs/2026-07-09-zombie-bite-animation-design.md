# ゾンビの意志 噛みつきアニメーション設計

## 目的

屍石が隣接する敵通常石を感染させる際、攻撃元と対象の関係、噛みついた瞬間、屍石への変化を順序立てて表示する。演出は「不気味な影の顎」を採用し、盤面の視認性と既存のターン開始演出順を維持する。

## 表現

1. 攻撃元の屍石が短く紫黒に脈動する。
2. 攻撃元から対象へ細い黒紫の影が這う。
3. 対象石の上下または左右に半透明の牙が現れ、対象へ閉じる。
4. 牙が閉じた瞬間に対象石を小さく歪ませ、紫の脈を一度走らせる。
5. 演出完了後、対象を屍石の表示へ更新する。

1回の演出時間は約800msとする。盤面全体の揺れ、飛沫、大きな暗転は使わない。

## イベントと責務

- `game/` は感染結果と攻撃元・対象座標を決定し、順序付きイベントとして返す。
- `game/` はDOM、CSS、タイマー、音声を参照しない。
- `ui/` は感染イベントを受け、既存のAnimationEngineとSingle Visual Writerの管理下で演出する。
- 感染による盤面状態の確定はゲームロジックを正本とし、アニメーション結果からゲーム状態を決めない。
- 対象が存在しない不発時は噛みつきアニメーションを出さない。

感染イベントは既存のターン開始イベント形式を拡張し、次の情報をUIへ渡す。

```text
type: zombie_infected_start
source: { row, col }
details: [{ row, col }]
```

## 再生順

- 複数の屍石は既存の `createdSeq` 順で1体ずつ処理する。
- 1体が複数対象を持てる将来拡張でも、対象は逐次再生する。
- 盤面の屍石表示への更新は、牙が閉じた後に見えるよう再生イベントを配置する。
- 噛みつき効果音 `zombie_will_bite` は同一感染バッチで1回だけ再生し、配置音は鳴らさない。

## DOMとCSS

- 盤面上に一時的な演出レイヤーを作り、攻撃元・対象セルの中心座標から位置を計算する。
- 影の経路は回転した細い要素、牙は上下または左右の2要素で構成する。
- 牙の向きは攻撃元から対象への方向に合わせる。
- 演出要素は `pointer-events: none` とし、終了・中断・盤面再描画時に必ず除去する。
- 固定ピクセル座標を状態として保持せず、再生開始時のセル矩形から算出する。

## アクセシビリティと縮退

- `prefers-reduced-motion` またはゲーム内アニメーション無効時は、移動する影と牙の収束を省略する。
- 縮退時は対象セルを短く紫色に強調し、状態更新を妨げず即座に完了する。
- 対象セルや盤面DOMが取得できない場合もイベント再生を完了扱いにし、ゲーム進行を止めない。

## 検証

- 感染イベントが攻撃元と対象を保持することをfocused testで確認する。
- AnimationEngineが感染イベントを専用ハンドラへ振り分けることを確認する。
- 複数感染時もイベント順が維持され、効果音が1回だけであることを確認する。
- 不発時にアニメーションイベントが生成されないことを確認する。
- DOM演出の終了後に一時要素が残らないことを確認する。
- 実機ゲーム確認は、ユーザーから別途明示された場合に実施する。
