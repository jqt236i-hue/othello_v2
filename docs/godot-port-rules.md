# Godot 移植用の対局ルールとカード索引

この資料は既存仕様を移植担当へ渡すための現行案内です。一次情報は [01-rulebook.md](../01-rulebook.md)、カード名・ID・コストは [catalog.json](../cards/catalog.json)、詳細は [カード仕様](../正本/カード仕様正本.md)、共通の例外は [共通ルール](../正本/共通ルール正本.md)、処理順は [ターン進行](../正本/ターン進行正本.md) です。新ルールを定義せず、UIやCPUの推測をゲームルールへ取り込みません。末尾のカード対応表はこの採用時点の索引で、全有効94種と派生専用6種を含みます。

## 状態の所有者と通常の一手

`gameState` は盤面・手番・連続パス・ラウンド進行、`cardState` は布石・手札・山札・カードcopy ID・石ID・特殊石本体・付与状態・マス効果・pending・各履歴、`prngState` はcanonical乱数を所有します。公開境界は [game/battle](../game/battle/index.ts)、詳細な責務分担は [architecture-contracts §6–10](architecture-contracts.md)。石の座標だけを識別子にせず、移動した同じ石のIDと、新たに生まれた石のIDを区別します。

描画側はこれを読むprojectionであり、アニメーション進捗・入力ロック・再生済みイベント・音声ハンドルをゲームの勝敗状態に混ぜません。ルール計算の完了と演出の完了は別です。ルールが確定しても、その操作の画面・音・布石差分の再生が完了するまで次の入力を通しません。

1. 前の演出と入力ロックを完了する。
2. ラウンドボーナス、開始前の返済・不足処理を済ませる。
3. ターン開始時点の治癒マスにいる所有者の特殊石本体へ寿命+3を適用し、開始効果を登場順で処理する。
4. 手札上限5枚まで山札から1枚ドローする。満杯・山札枯渇ならそのドローは失われ、山札を補充しない。
5. 配置前にカード使用または手札破壊を行える。原則1手番1枚使用、必要布石がなければ使用しない。公開通常行動のカード解禁は6手目以後で、CPUプロフィール固有の解禁はCPU資料で別管理する。
6. 通常配置・対象選択の解決・パスへ進む。使用で即時に手番が終わるカードを除き、カード解決後も通常配置を行う。
7. 配置、挟み反転、配置直後効果、融合再判定、布石加算を順に完了する。
8. 手番終了の毒・灼熱カウントと特殊マスを処理し、終了判定後に手番交代する。

ターン開始は1回だけです。pendingを選び直した時、追加配置した時、保存から再開した時にドロー・支払い・寿命減算を再実行してはいけません。開始済みかは保存のphaseで保持します。運命の意志は「操作する人」と「手番の所有者」を分け、カード・布石・配置色は所有者側で処理します。

通常合法手は空きマスから8方向に相手石を1個以上挟める配置。反転無効石を反転しなければ成立しない列は合法になりません。幽体石は反転対象にはなり、その石だけ色が変わらないので、この違いを合法手判定にも反映します。空きマスは石がないだけでは足りず、穴・円外・封鎖・凍結を除きます。自由配置カードと追加配置は個別規則を適用します。

合法手0なら、使えるカードがあってもプレイヤーはパスを選べます。未解決pendingはパスで捨て、既に消費したカードと布石は返しません。合法手0かつ使用可能カード0なら自動/強制パスへ進みます。未解決対象選択がある間に自動パスを挟んではいけません。終局は黒白の連続2パスだけで、満盤・片側0石だけでは終局しません。最終石数が多い方の勝ち、同数なら引分です。

黒白がそれぞれ1回手番を完了したらラウンドが進みます。時間停止による同じ色の連続手番だけでは進めません。10/20/30…ラウンド開始時に両者へ `floor(round/2)` 布石を与え、通常の開始効果より先に確定します。

## 布石、破壊、反転、所有者変更

布石は0..99で上限を超えた分は切り捨てます。反転した石数はその効果の実行側へ即時加算、数字マス値は配置時に別加算します。破壊・通常石化・融合は反転報酬ではありません。数字マスは配置で消費したら、破壊で空いても復活しません。プロフィールの獲得倍率は報酬の最終値に適用し、初期所持・消費・返金・返済・損失・奪取には掛けません。

破壊は石を空へする試行です。幽体・回避・増殖・復活・生きる意志により最終的に残っても「破壊対象になった」ことと赤ハイライトを消しません。セル消滅は石ではなくマスを穴化し、不可侵以外の石ローカルな破壊耐性を通過します。反転は通常反転やカード反転、所有者変更は誘惑・捕獲などカード本文に従う別経路で、反転枚数報酬へ数えるかを混同しません。

生成・復活後の石は通常の挟み判定を行うのが原則ですが、理論の化身による出現は明示例外で、出現時反転も数字マス/反転布石もありません。転生は破壊・配置・復活ではなく本体交換です。元石の位置・色、独立した石状態・マス効果は保ち、元本体の寿命/回避回数は捨てて転生先の初期値にします。転生先の即時効果は転生確定後に発動し、その後に通常配置を続けます。

## 特殊石本体、付与状態、マス効果

| 区分 | 意味 | 主な例 |
| --- | --- | --- |
| 特殊石本体 | その石固有の働き・寿命。石数とは別の特殊個体数に数える | 弱い石、強い石、幽体、繁殖石、火石、罠、時限爆弾 |
| 石へ付与された状態 | 本体とは独立して石IDに追従する | 完全保護、生きる意志、毒、灼熱カウント、回避 |
| マス効果 | 石が移動しても元の座標へ残る | 穴、凍結、封鎖、種、毒マス、灼熱マス、治癒マス、数字マス |
| 顕現石 | 不可侵を持つ特殊カード由来の本体 | 理論の化身、盤理の観測者、盤界の執行者 |
| 2×2本体 | 4マスを占有する1体 | 森羅万象神。石数は4、特殊本体数は1 |

一時マス効果（封鎖・凍結・種・毒・灼熱・治癒）は同じマスへ共存せず、新しいものが古いものを上書きします。穴は上書きしません。マスから既に付いた石状態が残るかは各効果の規則で決めます。

| 保護の種類 | 反転/破壊 | ほかの効果 |
| --- | --- | --- |
| 反転無効 | 反転しない。挟みの合法列を阻害する | 破壊や対象条件を満たす移動等は防がない |
| 完全保護 | 反転・破壊の対象として成立しない | 敵対・強制的な奪取/移動/弱体化も防ぐ。所有者の延命は受ける。意志の凍結というマス効果、セル消滅は別 |
| 幽体 | 対象にはなるが反転/破壊しない | 条件を満たす誘惑/捕獲/移動/マス効果は受ける。通常石専用の交換は対象外 |
| 回避 | 成功時だけ残り回数を1消費し、最寄りの有効空きへ移動 | 8方向距離の同距離候補は乱数選択。空きが全くなければ回避せず通常処理。移動後の反転主体は石の現色 |
| 不可侵 | 反転/破壊の対象外 | 移動、状態、寿命操作、セル消滅など干渉も対象外。自身の寿命と固有効果は進む |

森羅万象神の4マスは分離しません。不可侵を各マスに投影し、部分的な移動・反転・複製・穴化を認めません。火→水→草→雷の順で所有者開始効果を発動します。融合は通常破壊ではなく、素材消費や召喚場所の確保で破壊履歴・回避・復活・布石を発生させません。

## 同時効果、寿命、対象外

ターン開始は入口で処理個体集合を固定します。順序は `createdSeq`, canonical配列の `sourceIndex`, markerId。個体が途中で消えたら枠を飛ばし、同座標に新生した別個体へ枠を譲りません。途中で生まれた個体は次に条件を満たす開始時から発動します。対象・移動先・所有者・乱数結果は各枠を実行する時に確定します。

同じ石では本体→付与状態→寿命減算→持続終了処理。個別規則が優先し、最終回も効果を起こしてから通常石化するカードを、先に消してはいけません。石状態を本体とまとめても、同じセルにある凍結/種/穴/数字マスは同じ物理石の枠へまとめません。凍結セルの有効判定は開始入口で固定し、その開始中に期限切れになっても後続石が直ちに通過可能になるよう変更しません。

寿命の単位は一律ではありません。`remainingOwnerTurns` は所有者開始、`remainingTurns` 等は各効果の定義どおり、毒・灼熱の石状態とマスは黒白いずれかの手番完了を数えます。毒/灼熱/治癒を設置・付与したその手番末は減算しません。期限0の石状態は種類でまとめずcreatedSeq順に、破壊試行・回避/復活・状態解除まで1個ずつ完了し、その後で特殊マスを減算解除します。通常石化は破壊ではありません。

対象外条件はカード本文が基準です。「通常石のみ」「特殊石本体のみ」「石状態も含む」「罠・時限爆弾を含む」「完全保護」「不可侵」「持続ターンあり」を別々に判定します。盤上の表示ラベルだけから種類を推測しません。意志の凍結の使用可否は使用者に見える対象だけを使い、受理後のcanonical全体解決には非公開罠も含めます。公開された凍結マスから元の秘密罠情報を漏らしません。

## 盤面の穴と拡張

ベース盤は矩形4..16×4..16、円形は外接正方形6/8/10/12/14/16。円外は最初から存在せず、穴とは異なり因果再生で復元できません。通常の8×8以外を8×8配列へ切り詰めて移植しません。拡張はベース盤の外にも座標を持ち、負座標もあり得ます。

canonical表現はベースboard配列、`boardExpansion.cells`、明示的な穴marker。topology・描画境界・合法手候補はこの全体から再構成する派生情報です。`cells` が空配列でも存在すれば旧single-cellフィールドより優先します。石数・反転経路・対象列挙を配列の8×8ループだけで実装せず、[shared/board](../shared/board) の盤面契約へ合わせます。石・marker・石IDを含むマス変更は一括で検証して確定します。

## 遅延発動の移植用比較

[決定論比較の追加ライフサイクルケース](godot-port-conformance.md) で、時間停石・時間停神の発動と2／4連続手番、終了後の交代とラウンド、屍石の感染、時限爆弾の爆発、種の芽生えを具体的な入力・全状態出力として比較します。基本ケースのmarker生成だけでは遅延した主要効果の実装を保証しません。これらの境界と独立した仕様条件は [godot.conformance.test.ts](../test/godot.conformance.test.ts) で検証します。全寿命・全相互作用の網羅を意味せず、各行の既存意味テストを引き続き併用します。
