# UI位置・サイズ調整 依頼ガイド（Copilot向け）

このドキュメントは、UIの位置やサイズ調整を**短く正確に指示**するためのルールです。  
目的は「やり直しを減らして、1回で意図を伝える」ことです。

## 1. 先に決めること（必須）

調整依頼の前に、次の7点を必ず書きます。

1. 基準解像度（例: `1920x1080`）
2. 対象プロファイル（`16:9系` / `4:3タブレット系` / `iPhone縦系`）
3. 対象要素（ID/クラス名。例: `#card-detail-panel`）
4. 何を変えるか（位置 / サイズ / 両方）
5. 目標値（px, %, 倍率など）
6. 守る制約（例: 拡張マスに重ならない、指定プロファイルの計算を維持）
7. 確認する画面条件（例: 16:9 / 16:10 / 4:3、横持ち/縦持ち）
8. 完了条件（例: 「1920x1080で重なり0、文字のにじみなし」）

---

## 2. 指示テンプレート（そのまま使える）

以下をコピーして、`[]` 内だけ埋めてください。

```md
【目的】
[例: カード詳細UIを大きくしつつ、盤面に寄せる]

【基準解像度】
[例: 1920x1080]

【対象プロファイル】
[例: iPhone縦系（layout-profile-phone-portrait）]

【対象要素】
[例: #card-detail-panel, #hero-character-img, #cpu-character-img]

【変更内容】
- 位置: [どこへ / どれくらい]
- サイズ: [幅・高さ・倍率]
- 関連要素: [必要なら]

【数値指定】
- [例: パネル幅 320px 基準、右オフセットは side panel から +28px]
- [例: 勇者/モンスター画像は共通 0.8 倍]

【守る制約（壊してほしくないもの）】
- [例: 拡張マスに重ならない]
- [例: 指定したプロファイル（16:9系 / 4:3タブレット系）のレイアウト計算は維持]
- [例: iPhone横画面はブロック方針を維持]
- [例: 文字をぼかす縮小 transform は使わない]

【確認条件】
- [例: 1920x1080, 1600x1000, 1440x1080 で表示崩れなし]
- [例: hover時の拡大倍率は既存ルール維持]

【完了条件】
- [例: 要件を満たし、関連テストが通る]
```

---

## 3. 数値指定のルール（伝わりやすい書き方）

- 相対表現だけにしない（「少し右」だけはNG）
- 可能なら**基準値 + 変更量**で書く
  - 例: 「幅を `280px → 320px`」
  - 例: 「右寄せを `+24px → +28px`」
- 倍率は対象を明示する
  - 例: 「`#hero-character-img` と `#cpu-character-img` を `0.8` 倍」
- 「最大」「ギリギリ」は判定条件もセットで書く
  - 例: 「拡張マスとの重なり 0px を維持する範囲で最大」

---

## 4. 依頼の優先順位（競合を防ぐ）

指示が複数ある場合は、次の順で優先すると齟齬が減ります。

1. 仕様固定条件（重なり禁止、操作不能禁止など）
2. レイアウト安全条件（既存ロジック維持、他画面比率で崩れない）
3. 見た目目標（大きくする、寄せる、目立たせる）
4. 微調整（余白・フォント見え方・hover強さ）

---

## 5. 良い依頼例

```md
1920x1080基準で #card-detail-panel を調整してください。

- 幅は 320px 基準に拡大
- 右位置は side panel から +28px にして盤面へ寄せる
- 拡張マスには絶対に重ねない
- パネル内テキストがにじむ縮小 transform は使わない
- #hero-character-img と #cpu-character-img は共通 0.8 倍
- 16:10 と 4:3 でも崩れないこと
```

## 6. 避ける依頼例

```md
いい感じに大きくして右に寄せて。
```

理由:

- 数値がない
- どの要素か曖昧
- 何を壊してはいけないか不明

---

## 7. 追加修正の出し方（2回目以降）

2回目以降は、前回との差分だけを明記すると速くなります。

```md
前回からの変更点だけ:
- #card-detail-panel 幅: 320px → 336px
- 右オフセット: +28px → +24px
- それ以外のルールは前回どおり
```

---

## 8. 受け渡し時の短文テンプレ

時間がないときは、次の短文だけでも有効です。

```md
1920x1080基準。
対象プロファイルは 16:9系。
#card-detail-panel を「重なり0」の範囲で最大化して盤面側へ寄せる。
数値は変更前後を明記。
#hero-character-img と #cpu-character-img は 0.8 倍。
指定プロファイルのロジックは壊さない。
```
