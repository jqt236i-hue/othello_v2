# 究極労働神 実装計画

## 実装順

1. `01-rulebook.md` と `正本/` のカード、演出、効果音、ターン開始仕様を更新する。
2. カタログ、`CardType`、クイック説明、詳細説明、タグを追加する。
3. 特殊石レジストリ、配置時マーカー生成、理論の化身生成、捕獲元カード対応を追加する。
4. headlessの個体単位ターン開始処理を実装し、authority PRNG、布石台帳、通常破壊解決へ接続する。
5. 生きる意志復活時の確率初期化、ターン開始event、収入表示、吹き出し、ログ、音を接続する。
6. 石画像を移動・改名し、画像生成したカード背景を正規サイズへ収め、表示マップと生成manifestを更新する。
7. CPU評価を出稼ぎ系の長期収入アンカーとして追加する。
8. focused Jest、型検査、ブラウザbuild、ネットワークparity、Worker mirror、実機相当の最小ブラウザ確認を行う。
9. 差分と生成物を自己レビューし、タスク所有ファイルだけをコミットする。

## 必須テスト観点

- 配置時は確率0%で、最初の所有者ターンに1%へ上がってから抽選する。
- 抽選外れで布石+5、抽選当たりでは収入なし。
- 複数個体が登場順に独立抽選される。
- 凍結中はカウンタとPRNGが進まない。
- 自壊成功は通常破壊となり、破壊音と自壊台詞が1回だけ出る。
- 完全保護、幽体、破壊回避、増殖、復活、生きる意志で破壊が防がれた場合に、自壊成功台詞を出さない。
- 生きる意志復活で確率0%、救済神復活で通常石。
- 外部破壊では過去の未練を示す台詞、自壊では心が折れた台詞になる。
- snapshot・Worker・ローカルでカウンタと抽選結果が一致する。

## 自己レビューによる修正

- 既存の出稼ぎ一括処理は個体順と確率PRNGの境界に合わないため流用せず、ターン開始アンカー単位の新モジュールにする。
- `DESTROY`とは別の盤面削除経路を作らず、破壊演出・復活・救済・音の既存順序を保つ。
- 自壊専用吹き出しは `destroyAt` 実行前に出さず、返却された破壊結果が terminal destruction の場合だけ出す。
- ブラウザ表示変更を含むため、focused test後に `npm run build:browser` を必須とする。
- root実装を正本とし、`worker-public/` は `npm run worker:prepare` でのみ同期する。
