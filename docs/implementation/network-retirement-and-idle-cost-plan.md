# レート対戦撤去とネット対戦の待機負荷削減

役割: 今回の実装・検証の進捗記録。正本は `01-rulebook.md`、内部契約は `docs/architecture-contracts.md`。

## 要求と境界

- レート対戦、キュー、レート計算・ランキング・履歴・表示・専用APIを撤去する。
- 通常のネット対戦、スコアランキング、プロフィール、デッキ、観戦、演出、手番期限、再接続を維持する。
- Cloudflareでは接続を維持して休止できるWebSocketを使い、SSEは互換経路として残す。
- 生存確認をゲーム履歴と分離し、待機時の保存・稼働を減らす。
- 本番デプロイは今回の依頼に含めず、通常ローカル配信に反映する。既存の別作業の変更を保護する。

## 進捗

- 調査済み: レート専用処理はWorker、ローカルサーバー、UI、ビルド入口に分散。通常ランキング・IDは共有のため保持。
- 実装済み: レート対戦の画面・キュー・計算・履歴・API・専用型・テストの撤去。通常ランキングとプロフィールを保持。
- 実装済み: サーバーの能力通知、WebSocket休止・接続の復元・再認証・自動応答・SSEフォールバック。生存確認は履歴・保存・イベントIDから分離。
- 検証済み: ネット対戦parityの36スイート581項目。初回実行で失敗した状態取得・初期イベントID・カードparityの対象は、修正・ビルド後の再実行で通過。追加のUI/休止/型ビルド回帰7スイート47項目、通信とparity再確認4スイート67項目も通過。
- 検証済み: Wranglerローカル実行で部屋作成・参加・状態取得・着手・冪等再送・退出、WebSocket認証・相手手札秘匿・観測時の両手札公開・山札/乱数秘匿・再接続・自動応答。
- 完了: 最終 `worker:prepare`（`build:vite` を含む）、ブラウザ生成物検査、Worker mirror 1118ファイルの一致。通常配信の8000はHTTP 200で稼働。
- 復帰確認で発見した修正: 保存セッション復帰が、state応答に残る完了済み演出を取り込んでvisual rebaseと衝突していた。正規化入力の再生配列を明示して、復帰時の確定盤面への同期と整合させた。通常の回復再生は維持する。
- 検証済み: 復帰・同期の2スイート75項目。Vite/Pixiの通常URLで部屋作成・一覧から参加・観測・D3への通常クリック・3画面の状態一致・チャット・再読み込み復帰・WebSocket自動応答を確認。ブラウザエラー0。390×844の新規モバイル起動も盤面が画面内に収まり、レート対戦の要素はない。
- 8000の所有者: repoの `serve-with-fallback.js` 子プロセスPID 63436、親PID 4176。作業前から継続する2026-09-14 23:27起動のサーバーを再利用。試験用Wrangler/ブラウザは終了。
- `checkall` の残件: 既存 `scripts/perf/measure-production-selfplay.ts:17` の未使用型 `Policy`。今回の未使用型は削除し、該当検査の再実行で残件がこれだけであることを確認。途中の生成物不一致は再生成・個別再検査で解消した。
- コミット対象: 今回の正本・テスト・仕様・分離できる生成物。別作業のCPU/画像と混在するVite配信物などは、ローカルの最新ビルドを保ったまま未コミットで残す。
- 本番デプロイと料金計測は未実施。試験用SQLiteはOS一時ディレクトリに保持。終了済み試験フォルダーの削除は自動承認レビューに拒否され、詳細理由は返されなかった。

## ビルド前提の修正

既存の別作業で追加された訓練CLIが共有ゲーム型を参照するため、狭いrootDirでビルドが失敗した。訓練CLIのビルドを、依存グラフ全体の型検査と所有するCLIだけの出力に分け、出力先とソースマップを維持した。pending選択定義の空オブジェクトfallbackには型注釈のみを加えた。CPU仕様・訓練内容は変更していない。

## 費用面の確認範囲

WebSocketだけの部屋にはサーバーの定期タイマーがなく、接続確認の保存もないことを回帰テストで確認した。実際の休止時間と請求額は本番計測していない。SSE接続が残る部屋と、着手・チャット・期限処理などの実作業は引き続き実行時間を使う。

## 検証

- 型・ビルド、ネット対戦parity、影響するUI・ランキング・ID・生成契約の既存テスト。
- 休止から復帰した接続の復元、非公開情報の分離、失効トークン、再接続と生存確認の回帰テスト。
- Cloudflareローカルruntimeと実ブラウザで接続、対戦、観戦、再接続を確認。
- 最終 `build:vite` とWorker mirror検査、8000の所有者・継続起動・HTTP確認。
