# 究極労働神 実装設計

## 目的

コスト25の通常カード `ULTIMATE_WORK_GOD`（究極労働神）を追加する。使用後の次配置石を永続の特殊石 `ULTIMATE_WORK_GOD` にし、所有者ターン開始時に個体ごとの自壊確率を1ポイント上げてから抽選する。抽選に外れた場合は布石を5獲得し、当たった場合は通常の破壊解決を行う。

## 正本仕様

- 初期自壊確率は0%。配置直後には抽選しない。
- 所有者ターン開始時、凍結中でなければ自壊確率を1ポイント上げ、その更新後の確率で抽選する。最初の抽選は1%。
- 自壊抽選に外れた場合だけ布石を5獲得する。自壊抽選に当たったターンは、破壊が保護・回避・復活などで不成立になっても布石を得ない。
- 自壊は `BoardOps.destroyAt` の通常解決を使い、完全保護、幽体、破壊回避、増殖、復活、生きる意志、救済神を迂回しない。
- 生きる意志で究極労働神として復活した場合、自壊確率は0%へ戻す。救済神で復活した場合は既存仕様どおり通常石になる。
- 個体が複数ある場合は登場順に独立処理する。凍結中の個体は確率上昇も乱数消費も行わない。
- 持続ターンは持たず、延命・腐食の対象外。特殊石として誘惑・捕獲・意志の喪失・意志狩り・理論の化身の対象になる。

## データと権威

- カードID: `ultimate_work_god_01`
- カード種別: `ULTIMATE_WORK_GOD`
- マーカー種別: `ULTIMATE_WORK_GOD`
- マーカーデータ:
  - `ownerColor`
  - `selfDestructChancePercent`
- 乱数はターン開始処理から渡される authority PRNG のみを使う。UIは抽選しない。
- カウンタは canonical `cardState.markers` に保存し、既存snapshot投影でローカル、Worker、再接続へ伝播させる。新しいネットワークコマンドやクライアント権威は追加しない。

## 表示と音

- 収入成立時は `ULTIMATE_WORK_GOD_INCOME` を出し、出稼ぎ通常収入と同じ `charge_gain_common` を再生する。
- 実際に自壊した場合は既存 `DESTROY` を使い、通常の `stone_destroy` を再生する。
- 破壊が防がれた場合は、その結果に対応する既存演出・吹き出しを優先し、自壊成功の台詞や破壊音を出さない。
- 収入、自壊、外部破壊の吹き出しは `SPECIAL_STONE_BUBBLE` に統一し、石の近くへ表示する。
- 配置時の固有吹き出しと確率バッジは追加しない。

## 自己レビュー

- 「最初は0%」と「ターン開始ごとに1%上昇」の順序は曖昧にせず、最初の所有者ターンを1%抽選とした。
- 自壊を強制削除にすると共通破壊ルールを破るため、通常破壊へ統合した。
- 自壊抽選後に破壊が防がれた場合の無料収入は、リスクを二重に軽減してしまうため発生させない。
- 凍結中に確率やPRNGを進めると見た目とcanonical結果がずれるため、どちらも停止する。
- 台詞選択のランダム性はpresentation専用であり、対局結果を変えない。自壊判定のPRNGとは分離する。
