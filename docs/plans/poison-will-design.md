# 「毒殺の意志」実装設計

## 目的

カード「毒殺の意志」を、ブラウザ・headless・CPU・ネットワーク Worker の全経路で同一挙動になるよう追加する。

## プレイヤー向け仕様

- カード ID は `poison_will_01`、カード種別は `POISON_WILL`、表示分類は「殲滅」、コストは 8 とする。
- 任意の盤面セル 1 マスを選び、10 ターン持続する `POISON_CELL`（毒マス）にする。
- 毒マス上の石は所有者・通常石・特殊石を問わず `POISONED`（毒状態）になる。
- 毒状態は付与されたターンを数えず、その後に完了した黒または白の各ターンで 1 減り、0 になった時点で通常の「破壊」を 1 回試行する。
- 毒による破壊には既存の破壊回避・破壊時効果が適用され、試行後に元の毒状態を解除する。破壊後も石が毒マス上に残る、または毒マスへ移動した場合は改めて毒状態になる。
- 完全保護中は毒状態にならない。毒状態の石へ完全保護が付いた場合は毒状態を解除する。
- 不可侵の顕現は毒状態にならない。
- 毒状態は石と一緒に移動・反転する。毒マスはセルに残る。通常の石破壊では毒マスを消さず、セル自体の除去では毒マスも消える。
- 毒状態は石へ付く状態だが、黒白それぞれの完了ターンで減る専用カウントのため、所有者ターン式の延命・腐食の対象外とする。毒マスも盤面マーカーなので対象外とする。
- ターン終了時は、毒の破壊判定、毒マスの残りターン減少・消滅、終局判定の順に処理する。

## 状態モデル

既存の `cardState.markers` を正本とし、新しい独立状態ストアは作らない。

- `POISON_CELL`: `board_marker`
  - `row`, `col`
  - `remainingTurns: 10`
  - `appliedTurnNumber`
- `POISONED`: `stone_status`
  - `row`, `col`, `owner`
  - `remainingTurns: 5`
  - `appliedTurnNumber`

同一セル・同一種別は重複させない。毒状態の再接触は残りターンをリセットしない。

## 処理境界

- 純粋な対象抽出・マーカー操作・接触同期・ターン終了処理は `game/logic/` に置き、DOM・音・通信へ依存させない。
- カード選択は既存 pending-selection registry と `game/card-effects/selection-flow.ts` を利用する。
- ゲーム結果は既存 `events[]` と canonical state に記録し、UI はそれを描画する。
- Worker、ローカルサーバー、ブラウザ、headless は同じ CardLogic とターンパイプラインを使用する。クライアントだけの毒判定は作らない。
- Worker mirror とブラウザ生成物は root ソース変更後に既存スクリプトで生成する。

## ターン処理

1. 行動開始時の `turnNumber` を「完了対象ターン」として保持する。
2. 行動・移動・カード効果の解決後、盤面上の毒マスと石を同期する。
3. ターン完了時、付与ターンと異なる毒状態だけを減算する。
4. 0 になった毒状態は既存 `BoardOps.destroyAt` で破壊を試行し、元の毒マーカーを解除する。
5. 破壊回避などで盤上に残った石と毒マスを再同期する。
6. 毒マスを減算し、0 になったマーカーを解除する。
7. 既存の手番交代・終局処理へ進む。パスでも同じ処理を通す。

## 表示

- 毒マスは紫系の毒々しいセルオーバーレイとし、残りターンを小さく表示する。
- 毒状態の石は石全体を軽く紫へ寄せる。
- 石の右下へ紫の三角形マーカーを表示し、その中に毒殺までの残りターン数を表示する。
- 既存 Single Visual Writer を守り、diff renderer と status event playback の既存経路へ追加する。
- 専用音声は追加せず、既存のカード使用音・破壊音を使う。カードカタログの全件画像契約に従い、毒マスを主題にした専用カード面画像を追加する。

## CPU

- CPU は pending selection を既存ポリシー経路で解決する。
- 相手石、とくに価値の高い特殊石・角の石を優先し、味方石は強く避ける。
- 空きマスは将来の接触可能性を簡易評価し、合法手がある限り必ず選択できるようにする。

## 互換性とネットワーク

- action payload に `poisonTarget` を追加し、既存の選択カードと同じ正規化・検証・publish 経路を通す。
- snapshot の追加トップレベル項目は設けない。marker journal により自然に同期する。
- 古い snapshot に毒マーカーがなくても従来どおり読み込める。

## 自己レビュー

- 共通の使用可能判定にも `getPoisonTargets` を明示的に渡し、空きマスと既存石のどちらかが残る限り「使用」から対象選択へ進める。
- 仕様の曖昧点だった ID・種別・分類は既存命名規則に合わせて固定した。
- 延命・腐食は `remainingOwnerTurns` 契約であり、毒は `remainingTurns` 契約なので対象外とした。
- 毒マスをセル、毒状態を石へ所属させるため、移動・破壊時の marker 保持規則を分離する。
- 毒の致死処理を UI やタイマーへ置かず、既存破壊 API と canonical turn pipeline に置く。
- 付与ターン非減算は `appliedTurnNumber` で決定し、setTimeout や描画完了には依存しない。
- 完全保護・不可侵・パス・破壊回避・セル除去・ネットワーク再接続を明示的な検証対象に含める。

## 非対象

- 専用 SE、毒専用の破壊回避ルールは作らない。
- 長時間 selfplay や学習モデルの再訓練は行わない。
