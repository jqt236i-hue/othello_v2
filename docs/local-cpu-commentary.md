# ローカルCPU発話（固定文ランダム）

CPU発話は、外部推論やローカル推論を使わず、固定文の組み合わせで生成します。勇者側の発話は生成しません。

## 有効化

- 既定で有効です。
- 明示的に有効化する場合は `?cpuTalk=1` を付けます。
- 無効化する場合は `?cpuTalk=0` を付けます。

## 発話の決定条件

- 開幕 / 中盤 / 終盤
- 優勢 / 拮抗 / 劣勢
- イベント優先（カード使用、被カード使用、対象選択、パス、盤面急変）
- CPU自身の通常着手で角を取った直後は、角専用文面を即時に割り込み表示
- `turn_start` の通常文は、初期配置石だけの未着手盤面では出さず、最初の着手以後から有効化します

## 吹き出し表示

- 吹き出しは CPU 側のみ表示します。
- 新しい発話が来たタイミングで文面を上書き更新します。
- 1セリフは、おおよそ全角60文字以内を目安にします。

## 固定文データの配置

- 発話データ: `game/ai/commentary-data.ts`
- 選択ロジック: `game/ai/fixed-commentary-engine.ts`
- 実行入口: `game/ai/cpu-commentary-runtime.ts`
- `card_used` / `card_used_by_enemy` のカード名・効果要約は `cards/catalog.json` / `shared-constants.js` を正本に取り込み、現行 catalog の全 `card type` を対象に生成します。

## レベル別トーン

- Lv1-2: `ゴブリン`
- Lv3-5: `盤上の主`
- Lv6: `観測者`

吹き出し本文は本人のセリフとして扱い、`ゴブリンは...` のような三人称ナレーションは使いません。基本は主語を省略し、接頭辞と語彙でレベル差を出します。

各レベル帯は雑談300文 / 優勢50文 / 劣勢50文 / 角取得30文 / 角被取得30文を持ちます。カード使用時 / 被カード使用時は、1カード種別×advantage ごとに 10文を生成します。

## 運用メモ

- 発話失敗時もゲーム進行は止まりません。
- 直近発話の再利用を避けるため、同文連発を抑制します。
- ネット対戦時は、受信した相手操作スナップショットに応じて CPU 側発話を生成します。
