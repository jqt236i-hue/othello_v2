# ローカルCPU/勇者発話（固定文ランダム）

CPU発話と勇者発話は、外部推論やローカル推論を使わず、固定文の組み合わせで生成します。

## 有効化

- 既定で有効です。
- 明示的に有効化する場合は `?cpuTalk=1` を付けます。
- 無効化する場合は `?cpuTalk=0` を付けます。

## 発話の決定条件

- 開幕 / 中盤 / 終盤
- 優勢 / 拮抗 / 劣勢
- 優勢 / 劣勢は、石差だけでなく、局面フェーズに応じた重み付き評価（石差、合法手差、角差、辺差、空き角に隣接する `X/C` 危険マス差）で判定します
- 序盤は角・合法手・空き角隣接の危険度を重視し、終盤は石差の重みを強めます
- イベント優先（カード使用、被カード使用、対象選択、パス、盤面急変）
- CPU自身の通常着手で角を取った直後は、角専用文面を即時に割り込み表示
- `turn_start` の通常文は、初期配置石だけの未着手盤面では出さず、最初の着手以後から有効化します
- 同一状況が続いた回数（雑談・煽り・ネガティブ・強がりの切替）

## 吹き出し表示

- 吹き出しは時間で自動消去しません。
- 新しい発話が来たタイミングで文面を上書き更新します。
- 1セリフは、おおよそ全角60文字以内を目安にして読みやすさを優先します。

## 固定文データの配置

- 発話データ: `data/dialogue/fixed-commentary-data.js`
- 選択ロジック: `game/ai/fixed-commentary-engine.js`
- 実行入口: `game/ai/cpu-commentary-runtime.js`
- `card_used` / `card_used_by_enemy` のカード名・効果要約は `cards/catalog.json` / `shared-constants.js` を正本に取り込み、現行 catalog の全 `card type` を対象に生成します。
- `card_used` / `card_used_by_enemy` は、カード名だけでなく、そのカードが何をするかの効果要約を必ず本文へ含めます。

## 勇者側の発話

- 勇者側も同じ runtime / `eventType` 系を使いますが、CPUとは別の勇者用文面プールを使い、通常ログでは `勇者:` プレフィックスで表示します。
- ローカルCPU対戦では黒側の勇者だけが自端末で発話します。
- ネット対戦では各端末が自席の勇者発話だけをローカル生成し、相手端末の勇者発話をネットワーク経由で共有しません。
- 勇者の文面トーンは、前世であらゆる盤上勝負を制して飽きてしまった背景を残しつつ、自然な言い回しの中に生意気なガキっぽい軽口と余裕を混ぜる方向で統一します。
- 勇者は `turn_start` に加えて、自分の `card_used` と相手の `card_used_by_enemy` に反応します。
- 勇者側のカード反応文も、カード名と効果要約を含めて現行 catalog の全 `card type` を対象に生成します。

## 勇者用固定文プール

- 雑談系 `heroChatterLines`: 300文
- 優勢系 `heroAheadLines`: 50文
- 劣勢系 `heroBehindLines`: 50文
- 角取得系 `heroCornerGainLines`: 30文
- 角被取得系 `heroCornerLossLines`: 30文
- `card_used` / `card_used_by_enemy` の勇者側カード反応文は、1カード種別×advantage ごとに 10文へ固定します。
- CPU の優勢 / 劣勢の通常ターン文は、`Lv1-2` / `Lv3-5` / `Lv6` の全レベル帯で、高揚 / 焦り / 執念が伝わる感情寄りの文面にします。

## 運用メモ

- 発話失敗時もゲーム進行は止まりません。
- 直近発話の再利用を避けるため、同文連発を抑制します。
- ネット対戦時は、受信した相手操作スナップショットに応じて発話を生成します。
- 角取得系イベントは専用文面プールを持ち、CPUが角を取った直後はランダムな専用セリフへ即時に切り替わります。
- `card_used` / `card_used_by_enemy` はカード名だけでなく、効果の要約（何をするカードか）が必ず分かる文面を含みます。
- 通常ターン文は、局面に合う候補プールを複数まとめ、候補プール間は均等寄り・各プール内はランダムに選ぶよう調整しています。
- 最後に口調整形を行い、出力ごとの語尾と勢いを同じキャラ調へ揃えています。
- 非カード固定文（開始/通常/盤面揺れ/パス/対象指定/角取得）は合計119200文に固定しています。
- 内訳は、基本文プール100000文、角取得系プール19200文です。
- カード使用時 / 被カード使用時の文面プールは、1カード種別×advantage ごとに 480文へ調整しています。
