# ローカルCPU発話（固定文ランダム）

CPU発話は、外部推論やローカル推論を使わず、固定文の組み合わせで生成します。

## 有効化

- 既定で有効です。
- 明示的に有効化する場合は `?cpuTalk=1` を付けます。
- 無効化する場合は `?cpuTalk=0` を付けます。

## 発話の決定条件

- 開幕 / 中盤 / 終盤
- 優勢 / 拮抗 / 劣勢
- イベント優先（カード使用、被カード使用、対象選択、パス、盤面急変）
- 同一状況が続いた回数（雑談・煽り・ネガティブ・強がりの切替）

## 吹き出し表示

- 吹き出しは時間で自動消去しません。
- 新しい発話が来たタイミングで文面を上書き更新します。

## 固定文データの配置

- 発話データ: `data/dialogue/fixed-commentary-data.js`
- 選択ロジック: `game/ai/fixed-commentary-engine.js`
- 実行入口: `game/ai/cpu-commentary-runtime.js`

## 運用メモ

- 発話失敗時もゲーム進行は止まりません。
- 直近発話の再利用を避けるため、同文連発を抑制します。
- ネット対戦時は、受信した相手操作スナップショットに応じて発話を生成します。
- `card_used` / `card_used_by_enemy` はカード名だけでなく、効果の要約（何をするカードか）が分かる文面を含みます。
- 通常ターン文は、煽り・強がり・悲鳴を含む感情強めのトーンを優先するよう調整しています。
- 最後に口調整形を行い、出力ごとの語尾と勢いを同じキャラ調へ揃えています。
- 基本文プール（開始/通常/盤面揺れ/パス/対象指定）は合計100文に固定しています。
