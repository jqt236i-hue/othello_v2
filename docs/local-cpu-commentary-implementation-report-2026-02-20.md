# ローカルCPU発話機能 実装記録（2026-02-20）

## 1. この記録の目的
この文書は、今回の依頼に対して私が行った作業を、後から見返せる形で詳細に残すための記録です。
対象は「ローカルで動く量子版モデルを使い、CPUが盤面状況に応じて短い文章を出す機能」です。

---

## 2. 依頼の要点（実装対象）
- CPUが対局中に、状況に応じた短文を出せるようにする
- ローカル実行を前提にする
- 既存の対局進行を壊さない（失敗しても試合が止まらない）
- 既定では無効、必要なときだけ有効化する

---

## 3. 進め方の方針

### 3.1 既存構成への影響を最小化
- 既存のCPUターン処理に「発話要求」を差し込むだけにし、勝敗判定や置石ロジックは変更しない
- 発話が失敗しても無視し、ターン進行を最優先する

### 3.2 明示的な有効化
- 既定は無効
- URLクエリ `?cpuTalk=1` または `window.CPU_TALK_ENABLED=true` のときだけ有効

### 3.3 ローカル完結
- ゲーム本体はローカルの橋渡しサーバへ短い文脈を送る
- 橋渡しサーバがローカル推論側に問い合わせる
- 失敗時は短い固定文で安全にフォールバック

---

## 5. 動作設計（要点）

### 5.1 データの流れ
1. CPUターン処理が対象タイミングで文脈を作成
2. ブラウザ側ランタイムがローカル橋渡しへPOST
3. 橋渡しがローカル推論へ問い合わせ
4. 短文を受け取り、通常ログへ表示

### 5.2 安全設計
- 発話は完全に補助機能（失敗しても試合は進行）
- 連続呼び出しを抑え、過剰発話を防止
- 返答文を短く整えて表示乱れを抑制
