失敗/不採用の調査方法:

- `smoke-v1`: 汎用Playwright起動ではソフトウェア描画からDOM compatibilityへ落ち、未使用の `crystal_stone.png` 不在で起動失敗。通常GPU設定では起動するため、既存の `createDesktopChromiumLaunchOptions` を採用。既存画像やルールは変更しない。
- `smoke-v2`: 正本パイプラインの全呼出しを採取するとLv9内部の探索試行まで混入した。v3は実際のgame/cardオブジェクトの同一性を確認してから記録し、探索中の複製/ログ負荷を除いた。v2は強さ・計時の証拠として使わない。
- v2とv3のseed91310002は開始局面/手札/数字マス/PRNGが完全一致したが終局結果は異なった。既存CPUに時間制限探索があるため、固定seedだけで選択列まで一致するとは断定しない。最終評価は実行コード・予算・ハードウェア・全行動・乱数対応を保存し、都合の良い実行結果を選ばない。
- 既存 `run-ui-level-match` の結果集計はbase matrixのみ。新しい評価では必ず正本の拡張込み集計に置き換える。
