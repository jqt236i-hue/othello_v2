# PR2 v2 最終レポート

## 一行結論

PR2 v2 の `syncBoardPixelSizing` dirty gate は、Playwright 計測上では通常 render の多くを skip 側に寄せられており、`othello:syncBoardPixelSizing` は median 0.100ms / p95 2.300ms まで低下した。挙動変更を狙わない軽量化として継続可。

## 変更内容

- PR2: `syncBoardPixelSizing()` に dirty flag + signature gate を追加。
- PR2 v2: signature を拡張し、board/frame identity、skin id、layout scale、frame layout vars、devicePixelRatio、page-state triggers を考慮する形に補強。
- PR1/PR1.5 の `?perf=1` instrumentation を使い、通常 path では計測コストが乗らない状態で測定。

## 計測方法

- Script: `scripts/perf/measure-pr2-v2.ts`
- Run: `npm run build:browser` 後に `node dist/scripts/perf/measure-pr2-v2.js`
- Browser: Playwright Chromium headless
- URL: `/?perf=1`
- Iterations: 3
- Scenario: 起動後 warmup、`renderBoard()` 連続実行、合法手クリック、viewport resize、board/frame skin 切替、`visibilitychange` / `pageshow` 相当、追加 render loop
- Output:
  - `docs/perf/2026-07-06-pr2-v2.json`
  - `docs/perf/2026-07-06-pr2-v2.md`

## 読み取り

- `syncBoardPixelSizing` の median が 0.100ms なので、通常 render は skip path に入っている。
- p95 2.300ms、max 22.300ms は resize / skin / page-state trigger など full sync が必要なケースを含むため、二峰性は期待通り。
- `renderBoardDiff` は median 0.800ms / p95 1.200ms と、この headless scenario ではすでに軽い。
- reconcile 3 パス合計は median 約 0.400ms、p95 約 0.800ms。N4 は効果が薄めなので、優先度は N1 より下げてよい。
- `buildCurrentCellState` は median 0.200ms / p95 0.400ms。N2 は現時点では見送り候補。
- 今回の scenario は headless の短時間測定で、特殊石 15-20 個の late game 手動 trace ではない。PR2 v2 の機械計測としては有効だが、体感評価は手動確認で補う。

## 手動確認項目

- 通常の序盤配置で盤面サイズ・石サイズが崩れない。
- 中盤以降、石が増えた状態で flip 後に盤面が古いサイズのまま残らない。
- ウィンドウリサイズ後に board/frame/cell が追従する。
- board skin 切替後に盤面背景と cell サイズが破綻しない。
- board frame skin 切替後に frame padding と board 位置が破綻しない。
- タブ切り替え復帰後に board がずれない。
- 盤面拡張/縮小カードのあと、拡張セルと frame oversize 表示がずれない。
- `?perf=1` なしの通常起動で `othello:*` entries が出ない。
- `?perf=1` 起動で `othello:syncBoardPixelSizing:measure` が skip/full の二峰性を持つ。
